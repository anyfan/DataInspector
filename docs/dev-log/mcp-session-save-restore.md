## 使用入口

- 工具栏“会话 → 保存会话…”或 `Ctrl+S`：选择保存位置。
- “会话 → 恢复会话…”或 `Ctrl+Shift+O`：选择会话文件；存在已加载文件时弹出替换确认。
- 默认 `.disession`，也接受 `.json`。内容为可读 JSON；不复制原始数据。
- 保存成功、恢复进度和完成结果显示于状态栏；错误另有模态提示。

## 保存内容

- 数据文件路径，优先相对于会话目录，必要时使用绝对路径。
- 行列布局、活动子图、最大化子图。
- 全部已加载信号（含未勾选信号）的来源身份、原始名称、显示名称、颜色、线宽、线型及时间偏移。
- 每个子图的信号绑定、Y 范围、Y 归一化和绘图项线宽。
- 共享 X 范围、游标模式和两个游标位置，包括隐藏/位于视窗之外的位置。

应用主题、窗口大小、全屏状态、搜索过滤和树节点展开状态不属于此版本的会话内容。

## 格式与身份

`src/quick/sessiondocument.h` / `src/quick/sessiondocument.cpp` 定义格式：

- `format = "DataInspectorSession"`，`version = 1`。
- `files[].path` 以会话文件所在目录为相对路径基准。
- `signals[]` 的身份为文件索引、表序号、源列序号，同时保留表名和信号原始名作校验；显示名称单独保存。
- `plots[].signals` 引用本文件中 `signals[]` 的索引，不引用临时运行时 ID。
- `layout`、`xRange`、`cursor` 及 `plots[].yRange` 描述视图状态。
- 严格检查格式版本、必填字段、有限数值、正序范围、1–8 行/列、有效索引、重复身份/绑定、颜色及样式。会话文件上限 16 MiB，文件记录上限 10,000，信号记录上限 100,000。
- 使用 `QSaveFile` 原子保存；验证或写入失败不替换现有会话文件。

原始数据不以内容哈希锁定：结构与名称不变时允许数值更新。结构变化则拒绝恢复，避免把旧样式和绑定套给错误信号。

## 恢复流程

`src/quick/appcontroller_session.cpp` 将恢复分为以下阶段：

1. 空闲状态检查；读取并验证 JSON；解析相对路径、检查文件存在性、类型及重复来源。
2. 复用加载工作线程，按保存顺序读取文件并构建范围索引；加载结果暂存，不替换当前模型或曲线仓库。
3. 全部文件读取成功后，逐个验证表/列身份、原始名称、数量和偏移后时间范围。
4. 准备新的共享数据仓库，再一次性切换来源、模型、布局、绑定及样式。
5. 同步 QML 工具栏，再恢复范围与精确游标位置，最后结束忙碌状态。

任何上述可报告的文件、格式、结构或偏移校验失败都会丢弃暂存结果并保留当前会话。恢复期间禁用视图交互，并在控制器入口拒绝并行操作，防止加载队列和用户编辑混入恢复任务。

## 子图生命周期与游标

- 控制器保存子图视图缓存：恢复结束时即便 QML 子图尚未创建，后续 `attachPlot` 也会应用保存状态。
- 子图被销毁/替换时保留 Y 范围等状态，不被默认自适应覆盖。
- `PlotItem::restoreCursorState` 在锁内原子应用模式及两个位置，不吸附样本、不按可视范围裁剪。
- 普通子图游标同步也使用精确状态，避免接收方视窗裁剪改变共享位置。

## 边界

- 暂不包含自动保存、退出时未保存提示、缺失路径重定位向导、部分恢复、恢复中途取消或旧版本自动迁移。
- 事务式恢复需要同时保留旧数据和新加载数据，内存峰值可能高于直接清空后加载。
- 不声明对内存耗尽、进程崩溃或系统 I/O 故障具有完整回滚保障；这里的保留行为针对已处理的验证/加载错误。
- 不修改源数据；保存文件并不是数据备份。
