# 导入文件默认颜色固定

原实现使用工作区累计的 m_nextColorIndex 给原始列分配颜色；移除文件不回退游标，新增派生输出也会推进游标，造成同一文件重复导入的颜色变化。

appendLoadedTables 改为使用文件内从 0 开始的局部调色板序号，按各表和信号的解析顺序循环；保留累计游标推进以兼容派生输出分配。手动曲线样式及会话保存颜色仍保留，跨线程快照与渲染路径不变。

回归覆盖超过一轮调色板、追加其他文件和派生输出后导入、移除后重导入、清空后导入，以及追加时保留已有手动样式。更新会话恢复后追加文件的颜色断言，恢复的旧样式仍保留。

验证：Debug 主程序构建成功，appcontroller_test、session_test 全套通过，git diff --check 无格式错误。未更新正在运行的 Release 程序。
