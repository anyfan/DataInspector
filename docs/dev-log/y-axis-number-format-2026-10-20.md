# Y 轴常用数值显示修正

截图中的 2000、2500、10000 被显示成科学计数法，原因是 QuickPlot 将绝对值达到 1000 的 Y 刻度强制转成指数形式。

改为非零绝对值在 `0.001 ≤ |y| < 1000000` 时使用普通数字，默认 6 位有效数字并去掉末尾零；相邻刻度舍入后重复时使用内核提供的高精度标签。范围外保留科学计数法及自动增精度，零继续显示 `0`。仅调整 Y 刻度文本，不改数据、曲线几何或会话格式。

后续截图反馈：在约 `-27.2844202`、跨度约 `1e-7` 的窄窗口中，上述高精度普通标签产生了很长的小数。修正为默认标签因舍入重复时整轴使用科学计数法，按需增加精度以区分相邻刻度，零仍显示 `0`；保留千位／万位常规范围的普通数字。测试补充该截图的正负范围及万位数窄窗口。
