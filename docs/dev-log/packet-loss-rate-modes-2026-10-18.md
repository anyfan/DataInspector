# 丢包率累计/窗口模式

用户指出“丢包率”容易与累计丢包数的微分混淆。新增显式累计和时间窗口统计选择，窗口默认 1 秒。两者均为百分比；累计丢包数输出保持不变。推断缺失归属右端采样时刻，窗口为 (t−W,t]，无插值/均摊，未收到新样本时不额外发布点。

修改规则模型、校验/JSON/失效键、X/Y 求值、控制器读写/复制/默认输出名、自动识别任务参数、QML 对话框与摘要、CLI schema。窗口计算用双指针与既有累计缺失数组，按原始输入重新计算接收增量扣除，无新逐样本数组，保持原有值缓存预算和取消检查。

会话升级 v16；旧 v1–v15 默认累计，新格式严格要求 rateMode/rateWindowSeconds。切换保持输出 ID、样式和下游引用，自动率名称按模式更新，手工名称保留。新增回归覆盖 X、Y 三种计数模式、窗口边界/启动/长窗口/回绕/重复、参数拒绝、旧版默认、v16 恢复与样式、自动识别去重及真实 QML 模式编辑。

验证：Debug 全目标构建、qmllint 零 warning、13 个 CTest 套件及单独补跑的 automation_cli_test 全部通过，共 14 套；最终 QML 参数校验调整后补跑 objectManagerQml 通过。未更新正在运行的 Release 程序，未进行真实 GPU 手工验收。

## 改为三选一单项输出

用户明确选择下拉三选一，只生成选中的结果：累计丢包数、累计丢包率(%)、窗口丢包率(%)。新规则和自动识别默认 window；rateMode 增加 count，窗口时长仅 window 显示。自动识别按采样组/指标/窗口去重。新规则可在三指标间编辑并保留 ID、样式和下游引用。

会话升级 v17，旧双输出规则继续读取、计算与保存，不删除其既有结果。窗口计算改为从经校验的原始相邻样本重算缺失/接收增量，以双指针维护窗口，无额外逐样本数组，按单输出计缓存预算。核心仍保留旧双输出求值兼容。

三选一最终验证：Debug 全目标构建成功、qmllint 零 warning；13 个 CTest 套件及单独补跑的 automation_cli_test 全部通过，共 14 套。覆盖新单项数值、QML 三选项、默认窗口、旧双输出恢复与复制，以及删除来源后单输出图例清理。
