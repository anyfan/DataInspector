# 空配置删除确认

处理配置与对象共用控制器的内容判断：空配置直接删除，规则、字段配置、飞机参数或航迹关联需要确认；飞机自动生成的默认未绑定字段不算已配置内容。判断不依赖搜索过滤、结果数量或原始文件是否加载。

确认窗口保存目标 ID，接受时删除该目标；删除失败保留选择并显示控制器状态。源码和资源 QML 回归覆盖空配置、失败结果规则、取消、确认期间切换选择、字段绑定和飞机参数。

删除选中配置或字段后选择同位置下一项，末项删除后回退到剩余末项；删除非选中项保留选择。合并输出删除前面的行时同步前移活动索引，保留输出身份和输入组；航迹已有同样的索引处理，无需修改。回归覆盖首项、中间、末项、清空、非选中项及合并输出输入组保留。
