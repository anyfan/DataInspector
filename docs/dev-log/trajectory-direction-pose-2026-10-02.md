# 航迹旋转方向跳变与绝对视角读数

日期：2026-10-02。

## 原因与改动

有两条可导致反向感的代码路径：沿环拖动穿过参数奇异的圆心会注入接近 π 的角差；新手势从已显示帧起步后，上一轮待显示任务仍可能提交更靠前的旧方向，使画面先跳过去再回到新手势方向。

- 对鼠标事件整条线段检查环中心 8% 半径死区，进入/跨过时暂停角度更新，离开后重新设定环参数基准，避免半圈跳变。
- 新旋转手势递增 interactionEpoch，并将请求相机同步到已显示方向；后台任务捕获 epoch，提交时拒绝跨手势旧帧。单个手势内部仍允许中间帧发布，不反复取消而饿死预览。
- 角落读数从单次累计拖动量改为当前已显示相机的绝对 X/Y/Z 姿态角，与航迹、方向轴和环保持同一帧。
- 以俯视 XY 为零，使用 Rz·Ry·Rx 欧拉角，X/Z 为 ±180°、Y 为 ±90°；Y 奇异时采用等价 Z=0 表示。松开、再次抓取和适应视图不重置角度；完整圈数不作为姿态读数显示。
- 会话仍保存四元数，不变更版本或格式。用户手册与渲染、并发、测试文档同步更新。

## 验证

- Debug 全目标构建、QML 零警告检查通过。
- 进入/稀疏事件跨过环中心的回归通过，不引入半圈；待显示 120° 旧帧在新 11.46° 手势期间不会被显示。
- 连续两次旋转的绝对角累积、再次按下不归零、适应保留、俯视归零通过；普通及 ±90° Y 姿态分解可重建同一相机方向。
- 源码/编译 QML 回归验证读数绑定实际显示姿态；Windows/D3D11 编译 QML 窗口事件与截图检查通过。
