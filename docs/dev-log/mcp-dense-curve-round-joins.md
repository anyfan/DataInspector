# 密集曲线预览边缘凸点

2026-09-30

用户报告密集曲线在整体预览时出现细小凸点，放大后消失。

固定上下限的合成波形复现了几何覆盖不一致：独立线段四边形没有折点连接，近竖直段几乎不向 Y 方向扩展，而 LOD 桶极值次序变化产生的水平连接向 Y 扩展半线宽，看起来像孤立尖峰。

保留独立线段四边形，在折点追加半线宽半径的内接 16 边形圆角；直线连接跳过，重复投影点合并。原始样本、LOD 极值选择和游标查询不变。圆角增加几何顶点，尚未做大规模多曲线帧率基准。

验证：Debug 全构建通过；rendercore_test、plotitem_lod_test 通过。新增 2 万点、320 桶、三档线宽测试在修复前失败、修复后通过。现有 GPU raster/blend 测试在 Intel Iris Xe / D3D11 上通过，光栅覆盖与 QPainter 参考比值为 0.994301。未取得用户原始数据，未进行该数据的人工 GUI 验收、Release 或部署验证。

## 第二轮：残留的像素级凸点

用户反馈圆角只能降低出现频率，随后提供 `test_file/11040237.DAT.mat`、`p1`、`msec_gps_ext GPS毫秒`。用 SciPy 读取第 1 列时间和第 13 列数值，共 247511 个样本，时间 87.065–6274.815 秒；3300–3900 秒内每周期上限固定 990、下限固定 20。

第一轮测试只检查极值坐标附近有覆盖，不保证整个边缘的 GPU 像素一致。新增 247511 点、40 Hz 锯齿波的 D3D11 回归，在圆角版本复现上下沿各 1 像素差异。单纯叠加包络仍不足，最终对满足密度条件的桶使用矩形极值包络替代已被重叠包络覆盖的折线段；保留非重叠连接、稀疏数据和虚线。包络投影超过一个逻辑像素时停用，避免放大旧 LOD 产生色块；极值索引仍引用原始 LOD 点，兼容归一化。

GPU 验证：合成锯齿波和从用户 MAT 提取的原始两列数据，在 1840×900 逻辑像素视窗、五档 Y 亚像素偏移下，3300–3900 秒检查区间上下沿逐列差异均为 0 像素。现有 raster/blend 测试通过。补充 CPU 回归验证真实尖峰保留、NaN 分段和旧 LOD 放大禁用包络。仍未做人工完整 GUI、Release、部署或多曲线性能验收。

最终检查：Debug 全构建、DataInspector_qmllint 零 warning，以及 rendercore_test、plotitem_lod_test、appcontroller_test 均通过；git diff --check 通过。
