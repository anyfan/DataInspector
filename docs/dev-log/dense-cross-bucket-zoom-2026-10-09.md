# 密集曲线中间缩放的残留边缘凸点

2026-10-09

用户再次报告 GPS 毫秒曲线在约 1250–2700 秒视窗内上下边缘有细小凸点。原单桶振荡判据在整体预览有效，但中间缩放时周期跨越桶边界，部分桶未补包络，近竖直折线与水平极值连接的 Y 向覆盖因此不一致。

LOD 保存每桶原始变化摘要，用本桶及前后最多两个桶合并统计样本数、方向反转、累计变化和幅值。继续要求至少四个样本、两次反转、累计变化达到幅值三倍；每个候选只引用自身首尾 X 和自身极值，不传播邻桶峰值。NaN 分段后摘要清空。原折线与几何补偿路径保持完整，虚线与旧 LOD 放大条件继续由几何阶段限制；LOD 算法版本提升为 2。

## 验证

- 旧 LOD 配合新增 `--dense --zoomed` 回归，在 1200 逻辑像素宽度复现上下沿各 1 物理像素差异。
- 修复后 D3D11：合成波形整体/中间缩放、正常/压缩高度，以及原始 `gps-msec.csv` 中间缩放的正常/压缩高度，共六组，每组两种宽度、五档 Y 偏移，上下沿差异均为 0。
- 原始 GPS 中间缩放使用 3250–4700 秒视窗、3300–3900 秒恒定极值区间。截图范围内约 2152.14 秒的原始样本为 990，高于周围峰值 989，属于真实高点，保留。
- 原始发动机航向/俯仰：162 个阶跃连线探测点全部覆盖；最大积分线宽 3.74902 物理像素，与此前验证一致。默认 GPU 光栅检查通过。
- Debug/Release 应用构建成功；Debug qmllint 零 warning；两种配置的 rendercore/plotitem_lod 通过。Debug 控制器回归使用构建目录内可写 TEMP/TMP 后通过，53 项通过、两项未启用的性能测试跳过。
- 新增 CPU 跨桶周期回归，继续运行原有阶跃微抖动、孤立尖峰、NaN、虚线、放大与折线顶点保留检查。GPU 中间缩放正常/压缩用例注册至 `ENABLE_GPU_TESTS`。

未进行完整应用人工交互、部署包及帧率验收。原始 CSV 和光栅捕获保留在构建目录，不提交。

## 追加：选中加粗与平台式锯齿波

用户补充 `test_file/0911-1119-新飞管标称测试.DAT.mat`，p3 的 `H_milliSec 时间-毫秒`。固定五桶判定仍漏掉窄视窗中平台式锯齿波；选中增加线宽但判定范围不变。本次提取 221322 个原始样本，在 2600–3100 秒实际选中状态复现固定五桶版本的 GPU 边缘检查失败。

改为前后 2/4/8/16/32 桶的有界多尺度判定，记录首次满足原振荡阈值的最小适用线宽（半径的一半，以桶宽计）；几何按实际投影桶宽和选中后的有效线宽启用。LOD 算法版本提升为 3。原折线不删除，不传播邻桶极值；微抖动阶跃保护继续保留。新增 40 ms 采样、100 ms 平台保持的合成 GPU 用例，避免单纯连续锯齿波掩盖缺口。

原始列 CSV 与提取程序仅保留在构建目录。首次使用压缩 MAT 的两次局部列读取返回相同列，已改用完整 p3 读取后按列索引提取，并核对毫秒列数值；后续验证使用纠正后的 CSV。

追加验证结果：原始 H_milliSec 的实际选中加粗，正常/压缩 Y 轴各两种宽度、五档偏移，全部上下沿差异为 0。平台保持合成数据的同一选中回归通过；已有中间缩放、压缩波形及发动机阶跃回归通过，162 个连线点全部覆盖，积分线宽仍为 3.74902 物理像素。一次压缩波形抓图未获得曲线覆盖，单独重跑十组检查通过。Debug 构建、qmllint 及 rendercore/plotitem_lod/appcontroller 测试通过。
