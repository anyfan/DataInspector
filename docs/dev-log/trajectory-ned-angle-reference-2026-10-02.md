# 航迹 NED 坐标与角度零基准（2026-10-02）

用户最终确认北东地（NED）：X 北、Y 东、Z 向下。机体系前右下（FRD）与 NED 区分，XYZ 绑定保留原值，不推断姿态或转换机体系数据。

- 地理投影缓存北/东/向下记录高度差，升高时 Z 减小；原始纬度、经度、高度读数与导出不变。
- 零姿态为正视 YZ：北向屏幕内、东向右、地向下。对已显示相机计算 Qzero⁻¹·Qcamera，再分解 Rz·Ry·Rx 绝对角。
- 非自由相机先将 NED 变换到投影基。俯视 XY 为北上/东右，正视 YZ 为东右/地下，侧视 XZ 为北右/地下；二维 Z 正方向也向下。
- 地理方向标签为 X 北、Y 东、Z 地。会话格式不变；已保存的自由四元数仍按同一数值旋转，但原经纬度 ENU 显示方向不再作为本版本地理基准。
- 回归检查地理轴与高度符号、原始值、三轴零姿态方向、单轴角度、复合/奇异姿态重建、连续两次抓取与实际显示帧读数。
