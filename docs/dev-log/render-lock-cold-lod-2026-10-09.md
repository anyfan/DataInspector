# 渲染持锁与冷 LOD 优化试验（已撤回，2026-10-09）

> **状态：试验已撤回，仅保留方法与测量记录。** 下文的实现、测试和工具描述对应撤回前的试验版本，不代表当前源码，也不是待实施计划。配套 JSON 保留当时的原始测量数据。

## 撤回决定与当前状态

用户在查看结果后要求「下降了就不改了」。本次两项优化的代码、测试、构建配置及现行架构文档修改均已撤回，恢复至 `main` 的 `20a345269216c74c87cb111295262c49e4867d68`；恢复后 Debug、Release 完整重建成功。此次仅将本记录和原始 JSON 纳入开发日志，不恢复优化实现。

撤回依据是收益不均衡：匹配工具测得全局冷 LOD 中位数改善约 7.1/35.0 倍，但 1% 局部视窗中位数分别慢约 12.6%/13.0%，新增索引约 1.25/20 MiB 每信号并增加准备耗时。持锁及合成竞争显著减少，CPU 提交和实际窗口 GUI 等待没有稳定改善，不能据此承诺整体交互提速。不能把本轮结论概括成所有场景都变慢，也不能仅凭全局收益忽略局部退化和额外成本。

## 基线及实施顺序

分支 `codex/render-snapshot-index-lod`，原始 revision `20a345269216c74c87cb111295262c49e4867d68`。Windows 11，Intel64 Family 6 Model 186 Stepping 2、20 逻辑 CPU，Qt 6.8.3 / LLVM-MinGW Clang 17.0.6，Release `-O3 -DNDEBUG`，MAT 开启。不改导入排序、原始数组、游标、导出、会话或交互规则。

先阅读 AGENTS、整体/渲染/并发架构与构建/测试说明，configure/build 原始 Release。默认 TEMP 不可写导致初轮文件测试失败，使用构建内独立 TEMP/TMP 后原始 11 项 CTest 全通过（67.90s）。初始全局冷 LOD 百万/千万点分别为 19.3540/21.8579、190.4471/218.5258 ms（中位数/P95），几何为 1.3820/1.6216、1.4613/1.7985 ms。

## 冷 LOD、几何与准备成本

为了分离索引准备并按容量计数，用最终工具重测原 revision 的范围/LOD 算法：仅适配诊断签名与空结构字段，不构建新摘要。工作计数不在计时区内。每进程一条合成信号（正弦加周期尖峰）、1200 桶、40 次直接 build。冷指绕过已完成结果缓存，原始数组/索引常驻，不清空 CPU 缓存；局部为 1% 时间范围平移。

下表耗时均为原算法中位数/P95 → 最终中位数/P95，ms。扫描计数含原始循环、摘要入口及阈值重算，不计二分及固定数量的极值/端点读取。

| 样本数/视窗 | 冷 LOD ms | 几何 ms | 原始访问旧 → 新 | 摘要/请求 |
| --- | --- | --- | --- | --- |
| 100 万/全局 | 25.2565/42.1025 → 3.5772/4.5613 | 1.6021/3.6914 → 1.4719/1.8849 | 1000000 → 155155 | 3155 |
| 100 万/1% 局部 | 0.2929/0.4415 → 0.3297/0.4467 | 1.0812/1.3781 → 1.2457/1.4853 | 10002 → 10002 | 0 |
| 1000 万/全局 | 383.9226/562.1715 → 10.9540/12.7345 | 2.7178/4.5872 → 2.6180/3.1965 | 10000000 → 157621 | 7221 |

全局访问减少约 84.5%/98.4%，本轮相同工具的中位数提高约 7.1/35.0 倍；相对于最初原始基线为约 5.4/17.4 倍。初始/匹配基线差异说明主机调度/频率波动，不能选择一个倍率外推其他机器或真实文件。输出点及 denseBuckets 元数据与扫描路径逐项一致；几何算法未改，不把几何计时波动当成收益。

1% 局部每桶平均约 8/83 点，不足 128 点摘要，保留原始扫描，**没有加速**；本轮中位数约慢 13%，绝对差 0.037/0.282 ms。128 点选择限制内存成本，不以细视窗的小绝对收益换取更小叶子的额外内存。不均匀时间聚集也可能因平均密度启发式被保守地留在扫描路径。

索引准备含后台线程启动，是每进程单次观测，非中位数/P95；还需加 Store 安装时间（JSON 单列）。内存按 capacity/sizeof 估算，不计 allocator 元数据、任务及 GPU；Windows 工作集/峰值另保存在 JSON。

| --- | --- | --- |
| 100 万/全局 | 16.1686 → 24.0473 | 0.2501 → 1.5001 |
| 100 万/1% 局部 | 18.2083 → 24.1621 | 0.2501 → 1.5001 |

摘要 80 字节/节点，叶子数向上取二次幂，百万/千万点新增约 **1.25/20 MiB 每信号**；有限 Y 范围另为常数大小。提前 reserve 避免 Qt 扩容将摘要部分膨胀到约 2/32 MiB。画笔/偏移快照共享，后台只准备一次，不计入 64 MiB LOD 结果缓存预算。复杂缺口、阈值重算、乱序和细视窗仍可能扫描。

## 最终持锁及实际 GUI 等待

四条信号、1200×600、归一化/幅值排序、64 次 Y-only 重绘、复用 LOD。lock 从成功取得锁到捕获结束，不含 acquire/unlock；原始诊断回调/信号量唤醒在旧临界区，计入旧持锁时间。合成竞争是同 mutex 状态读取；真实窗口在 SG 捕获时投递 queued GUI 访问，包含 Qt 同步、事件调度及 OS 等待，不是物理输入到屏幕呈现延迟。

每格为旧中位数/P95 → 最终中位数/P95，ms；四信号 CPU 几何指标见完整 JSON。

| 每条样本数 | mutex 持有 | 合成竞争等待 | CPU 提交总耗时 | 实际窗口 GUI 排队 |
| --- | --- | --- | --- | --- |
| 100 万 | 6.3344/7.8727 → 0.0007/0.0020 | 6.3655/7.9324 → 0.0003/0.0007 | 6.4923/7.9726 → 5.5604/11.2786 | 17.3371/26.4971 → 11.6022/26.4831 |
| 1000 万 | 11.5031/14.3547 → 0.0016/0.0022 | 11.5726/14.3448 → 0.0004/0.0007 | 11.6163/14.4670 → 11.7155/19.7203 | 21.7509/32.3331 → 26.5178/27.5584 |

GUI 百万点中位数降低、P95 基本相同；千万点中位数增加、P95 降低，**没有稳定的交互等待收益**。Qt 在 updatePaintNode 同步阶段仍阻塞 GUI，锁外几何仍在该阶段，不宣称整体帧率或真实交互提速。

## 实现与验证

- 锁内同一次复制完整渲染输入；锁外幅值/排序/归一化/几何/QSG，只写渲染线程根节点。来源替换和旧 LOD 清空同锁；根节点弱来源身份不长期留住退役原始数组，捕获帧以强 const 指针保证生命周期。归一化正常列读取后台有限 Y 范围，缺失 X 的有限 Y 仍参与。
- 加载后台构建 128 点连续有限摘要及多级树。极值保留最早原始索引；摘要不跨桶/缺口，变化量/方向保留密集包络判定，阈值附近按原始顺序重算。GUI Store 兜底不构建新摘要；放大、边缘与乱序保留扫描。
- `indexedLodMatchesRawScan` 覆盖全部点/密集元数据、重复时间/同值极值、原始顺序、邻居、NaN/Inf 摘要边界、振荡/阶跃微抖/尖峰、阈值舍入/溢出、偏移、全局/局部/放大、乱序、计数与取消。
- 两线程同时读索引/LOD 时替换画笔/偏移并清空 Store；捕获后替换来源/样式/归一化/选中、退役旧所有者，验证锁已释放、当前帧一致、下一帧最新和过期任务拒绝。另回归缺失 X 的有限 Y 及特殊直接输入归一化。
- Release/Debug 完整构建成功；Fusion/offscreen CTest 各 **12/12**（76.55/90.21s），两目录 qmllint **零 warning**。瞬时 exe 链接占用通过重试解决，没有关闭用户进程。
- 最后补齐渲染/范围查询的空索引兜底，使这些路径也显式禁止构建新 LOD 摘要；两配置完整重建及 qmllint 再通过，核心三项再次全过（Release 7.93s / Debug 14.23s）。测量输入原本均有索引，此兜底不影响已记录基准。
- **硬件验证**：QSG_INFO 确认 threaded D3D11 选择 Intel Iris Xe（vendor 0x8086/device 0xA7A0）、MSAA 4。层级、普通光栅、密集和压缩密集四项 exit 0；输入后台准备新摘要，两种宽度/五档偏移十阶段边缘差均 0/0。构建目录保留 `gpu-{blend,raster,dense,compressed}.log`。

未验证真实业务文件性能、长时/多子图高负载输入延迟、GPU 帧率/上传计时、其他显卡/驱动/HiDPI、人工完整 GUI、TSan、干净环境部署。CPU 基准、offscreen 功能、此硬件有限像素回归分别成立，不能互相替代。
