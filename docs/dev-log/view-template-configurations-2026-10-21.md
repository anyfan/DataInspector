# 完整视图模板与 v5 迁移

根据本次用户要求，视图模板从仅绘图配置的 v5 升级为 v6。会话 v22 保持不变，仅支持 v5 模板读取后在内存补空配置和空输出身份；不回填旧文件未曾保存的对象/规则，不恢复 v1–v4 迁移。

模板保存全部对象及独立处理组，纳入字段引用的原始来源和所有规则输出；输出保持 processingId/outputId 归属，航迹保留 objectId。原始与派生信号均保留名称、画笔和共享枚举。v6 模板另存子图 blendOverlaps，v5 缺省为 false；SessionPlot 用内存可选值承载，v22 会话序列化不新增字段。位置/姿态约定、自动字宽、端序、逐输出参数与独立 merge 输入组沿用现行对象 JSON。

应用仅匹配原始来源，所有导入 ID 重新分配；现有配置保留。结构验证完成后切换浅拷贝的 Store 和模型，共享不可变数组；计算仍使用既有后台依赖调度及预算。撤销保留此前 Store、模型分组、配置及计算状态，一次恢复；本次计算发布会更新撤销代际。修改对象/规则会使撤销失效；对象定义只在 objectsChanged 时比较，不在游标查询中展开。默认范围在派生完成后适应结果，保留模板相机；固定范围不受重算影响。

CLI 增加 view_template_save/preview/apply/undo，派生任务只核对本次导入规则；切换 Store 时轮换服务 epoch。回归覆盖来源换列、已有配置保护、多输出及下游数值、原始与派生枚举、航迹关联、完整撤销、非法引用、v5 迁移及真实 Python CLI。
