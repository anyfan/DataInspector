# v0.6.0 发布整理

版本升至 0.6.0，更新记录归档至 2026-10-21。包含统一属性侧栏与子图交互、完整 v6 视图模板、CLI API 3 的能力发现、批量枚举、常用编辑操作、规则来源追溯及计算终态等待。会话仍为 v22，模板仅允许 v5 内存迁移。
