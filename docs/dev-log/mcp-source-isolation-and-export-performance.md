# 来源隔离、Y 范围索引、MAT 流式导出与快照查找优化

## 范围

本轮在上一轮未提交修复的基础上继续修改，保留已有 CSV/MAT 安全检查及回归测试，不创建 Git 提交。对应四项请求：同名文件导出错配、Y 自适应扫描、MAT 导出额外整表缓冲与取消延迟、系列快照嵌套查找。

## 1. 独立来源标识与导出时间基校验

### 身份与显示分离

每个系列保存规范化完整文件路径 `sourceFile` 和文件内的表序号 `sourceTable`。导出分组使用 `(sourceFile, sourceTable, timeOffset)` 的结构化键，显示名称不再决定来源身份，也不使用易碰撞的字符串拼接键。

同名文件在信号树中分配唯一的文件分组标签，例如 `same.csv`、`same.csv [2]`。标签与规范化路径建立映射；删除某个标签只移除对应来源，文件级时间偏移也不会作用于同名的另一个来源。移除与重新加载保留其他来源的状态；清空会同时清理映射。

### 防御性校验

XLSX 和 MAT 写入器在后台线程、创建目标输出前共同调用 `validateExportTimeBases`：

- 检查同表系列存在且样本数相同。
- 共享同一不可变时间向量、偏移相同的导入列直接通过，避免逐列重复扫描。
- 其他情况逐样本比较偏移后的时间；不使用模糊比较，配对 NaN 视为同位置缺失。
- 不匹配时明确报错，不默默套用第一列时间，不覆盖已有文件。
- 长时间比较每 4096 行检查取消。

回归：两个不同目录的 `same.csv` 带有不同时间列，独立分组、独立偏移、分别导出 XLSX/MAT；删除后另一来源仍保留。另有写入器级的时间值、长度和偏移不一致检查，以及独立分配但时间完全一致的合法情况。

## 2. 分块极值索引与 Y 自适应

新模块：`src/quick/render/plotrangeindex.h`、`src/quick/render/plotrangeindex.cpp`。

- 每 512 个原始样本形成一个极值摘要，在摘要上建立线段树；只统计时间和数值都有限的点，保持原来的 NaN/无效值语义。
- `DataLoadWorker::finishTables` 在加载线程完成索引构建，随后通过 `LoadedTable` 传递不可变索引。正常应用加载路径不在 GUI 线程逐点构建索引。
- `PlotSeriesStore` 接收并共享索引；画笔、时间偏移和系列重新编号不会复制或重建节点数组。
- 单调时间：二分确定样本区间，整块使用树查询，两端扫描少于 1024 个原始样本。复杂度为 O(log N + log(N/512) + 512)，而不是 O(可见样本数)。
- 乱序时间：整块在窗口外则跳过，完全在窗口内则合并；仅部分相交的块逐点扫描。极端乱序窗口仍可能退化至 O(N)，不宣称彻底消除所有大数据卡顿。
- 手工构造且未提供索引的内部调用保留一次构建的兼容路径；实际加载器会提供准备好的索引。

### 实测工作量

`tests/rendercore_test.cpp::indexedBoundsAvoidMillionPointScan` 对一百万个单调时间样本执行接近全范围查询：

| 指标 | 本轮结果 |
|---|---:|
| 边界原始样本扫描 | 574 |
| 极值索引节点读取 | 15 |
| 索引节点数组大小 | 163,840 字节（160 KiB） |

二分定位的访问另外计算；此结果是确定性工作量计数，不是 GPU 帧率、GUI 最大延迟或整进程内存峰值的承诺。另对重复时间、NaN 数值、乱序时间、多种窗口和时间偏移，与逐点参考计算对比全部范围结果。

## 3. MAT 5 分块写入与取消

新模块：`src/quick/mat5streamwriter.h`、`src/quick/mat5streamwriter.cpp`；导出规划保持在 `src/quick/matwriter.cpp`。

- 保留未压缩 MATLAB Level 5、`pN` double 矩阵、`pN_title` UTF-8 字符矩阵及原有表编号规则。
- 数值列按 MATLAB 列主序流式编码，单块最多 8192 个 double，即 64 KiB。
- 移除原来的 `rows * columns` 整表数值缓冲。数值工作缓冲从 O(行数 × 列数) 降为固定上限；标题编码及已有原始数据仍占内存，不把 64 KiB 描述成整个导出进程的内存上限。
- 直接写入 `QSaveFile` 的临时文件，去掉“完整临时 MAT → 再复制到 QSaveFile”的第二次整文件复制。
- 数值块间、标题写入块间及最终提交前检查取消；进度随实际写入推进，而不是只随内存填充推进。
- 不启用直接覆盖回退；取消或写入错误时不替换原文件。单次操作系统文件写入和最终原子提交不能强行抢占，因此不承诺固定毫秒数的取消延迟。
- MAT 5 字节序、矩阵尺寸、数据元素长度、8 字节对齐、2 GB 限制由独立 framing 模块校验。写出的数据通过第三方 matio 读取，以及已有应用导入/导出往返测试验证。

回归：跨越多个 8192 样本边界的完整值读取、NaN、时间偏移、中文标题、pN 编号、单调进度；开始写入前、首个矩阵写入中、最终提交前取消，均保留原文件且不残留临时文件。

## 4. 系列快照查找

`PlotSeriesStore` 增加 `series ID -> 数组位置` 的哈希索引，在系列集合更新时维护。快照按请求 ID 顺序进行哈希查找：平均 O(K)，不再对每个 ID 遍历全部 S 个系列（O(K × S)）。

保持既有行为：未知 ID 被忽略、请求顺序及重复 ID 保留、重复存储 ID 仍取第一项、旧快照保持不可变。增加 10,000 个系列的查询与变更回归，覆盖追加、删除重编号、画笔修改、偏移、清空和替换。
