# 构建、交互及会话优化（2026-10-08）

本批覆盖六项：共用编译库、信号树搜索、拖拽取消、会话重定位/未保存提醒、PNG 导出、性能基准及有预算的 LOD 缓存。

## 实现

- `di_app_core` 共用控制器/加载/数据导出，`di_plot_items` 共用时间图/航迹实现；避免应用和多个测试目标反复编译相同源码。独立 QML 模块保留自身注册包装器，两个库用 `qt_extract_metatypes` 提供 foreign 类型元数据。
- 数据来源变化时建立持久的分组行/祖先索引；过滤仅扫描名称，分组路径每组匹配一次，展开直接复用分组索引，保持原组出现顺序、搜索揭示折叠子项和来源行映射。输入延迟 150ms；清空搜索恢复原滚动位置。
- 拖拽修订号使 Esc、失焦和布局变化后同一按压不能重启手势。
- 重定位按会话文件索引映射实际来源，仍完整暂存并校验结构后才替换当前数据；成功后提醒重新保存路径。绑定、元数据、来源、范围/游标/相机和布局追踪未保存状态，关闭和替换提供保存/放弃/取消。
- Scene Graph `grabToImage` 捕获当前/全部子图，2 倍 PNG、单边 8192 上限，原子写入、可取消；全部导出暂时恢复平铺但不改变控制器最大化配置。捕获后将不可变 QImage 交给现有 DataExportWorker 后台编码写盘。
- 共享 LRU 精确匹配请求键和弱来源身份，按容量估算 64 MiB、最多 128 项；活动预览和原始数据不计入缓存预算。CPU 基准输出 JSON，支持真实导入及百万/千万点合成数据、10 万信号搜索，另记录 Windows 进程工作集峰值。

## 验证

2026-10-09 完成验证，Qt 6.8.3 / LLVM-MinGW，电脑 20 个逻辑处理器：

- Debug、Release 全量构建成功，两套 `DataInspector_qmllint` 零 warning。编译数据库中控制器/绘图共用源码各编译一次；未测量统一环境下的构建加速比例。
- Debug CTest 11/11 通过（73.37s）；Release CTest 11/11 通过（30.00s）。搜索等待明确改为等待防抖后的模型更新，避免用缓存 delegate 判断过滤结束。
- 新增清空搜索恢复滚动位置用例，两种配置离屏通过；会话重定位、未保存提示、Esc 取消、缓存来源身份/预算/淘汰和 PNG 取消保留文件已有自动化覆盖。
- D3D11 曲线光栅/叠加测试通过。PNG 在 Windows 175% 缩放下发现重复 DPR 放大，已按窗口 DPR 换算捕获尺寸，并在后台归一化至输出像素尺寸。独立 D3D11 当前图用例检查实际曲线像素通过，全部子图用例检查尺寸、最大化恢复和会话未修改通过；Release appcontroller 全套在尺寸修复后再次通过（12.58s）。
- 原生窗口两个用例连续运行时一次拖拽目标高亮检查失败，独立运行该用例通过；未进行完整人工 GUI 交互验收，不据此宣称原生窗口测试完全稳定。
