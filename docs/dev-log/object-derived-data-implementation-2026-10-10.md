# 对象与派生数据首版（2026-10-10）

## 范围

用户确认所有派生数据必须由对象创建和统一管理。本版实现对象/字段/规则稳定身份、绑定与配置复制、状态字拆位和位段、比例换算、三轴模长、限定公式（含比较与逻辑）、规则编辑与依赖保护、信号树/游标/导出接入、后台计算和 v7 会话恢复。关联航迹复用对象经纬高与欧拉姿态，字段与名称变化同步到多个子图。

界面入口在信号树上方；原始信号右键绑定对象，派生信号右键打开对象管理。管理窗口按对象显示字段和规则，结果可勾选绘图、改名，显示输入、参数和前八个样本预览。新规则只选择对象字段或此前输出，禁止跨对象及循环依赖；删除对象保留原始数据。

## 数据与线程

`objectdefinition.*` 保存定义、JSON 校验和纯计算；`appcontroller_objects.cpp` 管理 GUI 生命周期和任务。QThreadPool 任务捕获不可变原始快照及定义，不捕获控制器。取消、任务身份与 release/acquire 完成标志隔离过期结果。GUI 发布计算快照保留最新画笔；样式和名称不触发数据计算。

变更先清空旧结果，缺来源保留规则并显示错误。多输入严格校验样本数和包含偏移的时间，不插值。状态字只接受有限合法整数；无效样本与非法算术留空。预算限制计算值数组为 512 MiB，索引和时间另计，时间数组尽量共享。

Store 输出按对象/规则分组导出。会话 v7 保存对象与输出身份和完整定义，不保存数组，恢复后重新计算。后台结果发布不标记会话修改；已有会话事务校验和 v1–v6 读取保留。

## 阶梯与回归

位信号、位段和逻辑根公式使用阶梯几何。LOD 保留桶首尾、极值及前后邻点，防止孤立脉冲拉宽到桶尾；禁用此类序列的连续振荡包络。完整样本不插入拐点，游标仍读取实际计算样本。连续曲线复用原管线。

`objectdata_test` 包括 u8 的 0/1/5/128/255 与非法值、u32 高位、有符号位段、公式/逻辑/NaN、时间不一致、归属/循环校验、重新绑定/文件移除、保存恢复/未保存状态、配置复制、关联航迹/规则编辑、短脉冲，以及 QML 界面创建对象→绑定字段→派生规则的实际调用链与零运行警告。另验证 XLSX 导出列名、时间和值。
