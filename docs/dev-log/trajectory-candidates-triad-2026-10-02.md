# 航迹可用信号与小坐标轴拖动（2026-10-02）

用户要求左键拖动小坐标轴可旋转，并改为先从信号树选择信号到子图，再在子图中设置参数绑定。

- 方向坐标轴预览提供命中矩形，包含轴线和标签。QML 与原生 C++ 左键输入都以按下位置区分：三维小坐标轴区域旋转，其余画布平移；中键旋转和鼠标锚点缩放继续保留。二维不旋转。
- 每个航迹子图保存独立的可用信号列表，可添加超过三条信号，不自动映射轴。顶部三只 ComboBox 从此列表设置 X/Y/Z 或纬度/经度/高度；解绑保留可用信号，树移除来源清空其映射。已有来源跨轴选择交换两轴，时间图原绑定单独保留。
- 移除自动填轴、信号名猜测与临时绑定目标；坐标对话框同样仅使用该子图的信号。首次进入航迹复用已有时间图信号作为候选，轴仍由用户设置。
- 会话 v5 保存 `trajectory.signals`，校验有效且不重复、轴来源必须属于候选；兼容 v1–v4，旧轨迹由轴来源去重建立候选。删除文件与恢复按身份重映射可用列表和轴。
- 回归覆盖超过三个候选、独立轴绑定/交换/解绑、来源移除、子图隔离、未绑定信号会话往返、旧 v4 和错误候选校验，以及窗口级小坐标轴左键旋转与顶部下拉绑定。

验证：Debug 完整构建、qmllint 零 warning、8 个相关 CTest 套件通过（33.99 秒）；Windows 原生的 QML 交互、候选隔离、来源重映射、v1–v5 会话回归通过。D3D11 等轴测/俯视/自由旋转光栅检查通过。原生窗口事件验证小坐标轴左键旋转，局部 ComboBox 绑定和解绑保留候选；320×240 与 640×480 布局保持画布尺寸。缩小下拉指示器后原生与离屏 QML 检查通过，保证小子图仍能显示轴名。实际飞行数据人工手感、Release 构建和部署未验收。
