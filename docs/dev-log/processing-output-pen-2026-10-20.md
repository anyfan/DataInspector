# 处理输出线条预览

信号树短线抽为 SignalPenPreview，处理列表的每条输出复用颜色、宽度、线型和点击行为。使用 Qt Quick Shape，不增加 Canvas 或绘图库。处理列表按控制器绘图修订刷新画笔查询，点击复用 Main 的信号属性入口；不改变绘图勾选。

信号属性入口不再关闭对象／处理编辑页，侧栏与当前页面并列。回归断言点击输出短线及共用属性入口后处理页仍显示、配置选择保留且曲线网格仍隐藏。

信号树整行 MouseArea 在分发单击时优先识别短线，避免被规则输入／状态来源选择或属性跟随分支抢走。保留短线区域超过阈值后拖动信号的原行为；鼠标回归验证属性打开且规则输入和编辑页面保持，并验证整行留白和短线区域拖拽。
