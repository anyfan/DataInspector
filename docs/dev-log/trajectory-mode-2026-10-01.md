# 三维运动轨迹子图（2026-10-01）

- 沿用 Qt Quick Scene Graph，新增独立轨迹核心、渲染项、QML 视图和控制器实现，不引入 Quick3D 或新绘图库。
- 支持同时间基 XYZ、缺失断线、正交等比例投影、起终点、单/双时间游标位置、旋转/平移/缩放、预设视角、复位和视角撤销。
- 后台请求取消/合并，原始数据不可变，Scene Graph 节点与几何缓存复用；游标查询走 Store 原始样本索引。
- 保留各子图二维绑定，共享时间轴不被空间旋转修改；导出、删除文件、清空、布局和会话涵盖轨迹来源。
- 会话升级 v2，读取 v1 默认为二维；新增模式/XYZ/camera 的结构与数值校验。
- 当前为旋转投影，没有真实深度遮挡、模型/姿态、跨采样率重采样、地理坐标转换或重放。

验证结果：

- Debug 完整构建通过；`DataInspector_qmllint` 零 warning。
- CTest 11/11 通过（29.42 秒），包含时间基/缺失断线、三轴方向与大坐标精度、原始样本游标、混合子图与撤销、删除来源、v1/v2 会话、QML 对话框操作、后台最新请求与销毁取消。
- Windows 原生 QML 自动化通过：实际打开 XYZ 对话框、选择三轴、确认模式、等待构建并捕获界面。
- Intel Iris Xe / D3D11 硬件轨迹光栅检查通过：轨迹有可见像素，俯视切换改变画面。
- `git diff --check` 通过。未完成手工 GUI 验收、Release 构建或部署；未做百万级数据性能基准。当前验证不代表这些边界已通过。

空间坐标约定：X 横向、Y 纵向（前后）、Z 垂直（高度）；正视 XZ、俯视 XY、侧视 YZ，Z 为空间竖直轴。
