# 航迹默认选入绑定与角度轴色（2026-10-02）

- 新航迹子图默认经纬度；首次进入时已有时间图来源按列表顺序填充空轴。
- 信号树勾选、双击或拖入的新增信号按选入顺序填充首个空轴，三轴满后仅加入候选。已有绑定不被覆盖，手动留空和显式坐标模式在再次进入时保留；取消勾选清空用到该信号的轴，再次选入补空轴。
- 自动轴绑定经过 configureTrajectory，保持首次信号的共享时间范围适应路径；时间图绑定、子图隔离、会话格式维持原行为。不根据名称猜测纬度/经度/高度。
- 角落姿态读数使用富文本，X/Y/Z 数值分别为方向坐标轴的红 #d94b4b、绿 #27945b、蓝 #397bc5。当前手柄提示仍使用对应环色，三个角度各自的颜色不受它影响。
- 用户手册、架构概览和测试文档同步更新。回归覆盖默认模式、自动绑定顺序、满轴保留、补空轴、手动绑定/模式往返及源码/编译 QML 三色反馈。
