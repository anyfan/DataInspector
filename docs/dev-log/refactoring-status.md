## 游标性能回退修复

发现 `updateCursorValuesLocked()` 对每条信号重复调用全体信号查询，且底层查询线性扫描全部样本；游标绘制还重复生成及上传曲线几何。
现改为每个游标一次批量查询，有序时间使用二分定位，乱序保留原始顺序扫描。重复时间、等距样本和 NaN 的查询行为以参考扫描回归验证。
场景图节点记录曲线请求键，游标更新复用顶点；视窗、尺寸、数据、选择和画笔变化仍更新曲线。相同游标位置不重复通知。

Debug 离屏合成测试：16 条信号 × 100000 点，200 次游标查询和场景图提交共 32 ms。这不是 GPU 帧率，也没有与旧版做同机对照；长段缺失值查询及乱序时间仍可能线性扫描。

## 异步 LOD 与交互迁移

- LOD 使用独立双线程池；GUI 端每子图合并为一个最新请求，在途任务以原子取消标记每 1024 点检查退出。只发布当前请求结果，工作线程不访问 QObject/QSG。
- 数据替换清除旧预览，视窗变化保留上一份 LOD 重新投影。子图销毁取消任务，无需等待全量计算。
- 全局 X 适应取全部子图绑定数据的并集并留 2% 边距；Y 按当前 X 范围留 5% 边距，支持活动/全部子图。
- 按用户更正：图例左键定位信号树，不隐藏曲线；右键从当前子图移除。取消图例位置切换，只保留顶部。
- 迁移轴区单轴滚轮、游标 X/Y 格式切换和 Y 标签避让；曲线节点始终插入游标节点下方。
- 新增最新请求/清空/销毁异步测试、轴缩放和可见 Y 测试、真实 QML 加载及图例点击测试、游标场景图顺序测试。

多级缓存、按字节内存预算、几何后台生成和真实 GPU 性能基准仍属后续工作。

## 尖峰线条压窄：GPU 复现与修复

用户截图显示连续尖峰/折返线段变细。此前孤立斜线和直角测试未覆盖这种情况；受限 miter 在接近折返时把整段法向宽度压缩。
现改为每段独立等宽矩形及外侧圆弧接合，直线保留紧凑三角带。游标层级、选中曲线加粗、虚线和 NaN 分段保持。

新增 `plotitem_raster_test` 使用透明无焦点原生窗口，在真实 GPU 上捕获 24 段镜像尖峰，并与 QPainter 的同宽圆接合参考线比较。
Intel Iris Xe / D3D11 / 4x MSAA 实测：修复前着色量为参考值的 12.48%，修复后为 99.4333%；镜像两组总着色量差约 0.005%。图片位于 Release 构建目录 `plotitem-raster-before.png` 与 `plotitem-raster-after.png`。
此测试需要图形会话，可通过 `-DENABLE_GPU_TESTS=ON` 纳入 CTest；software 后端跳过，避免将空白离屏图误认为成功。
