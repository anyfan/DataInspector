# 游标交互修复

- 单游标切换双游标时保留 T1，在当前活动视窗生成并选中 T2；最近样本不在视窗内时保留视窗内时间位置。
- 左右键默认步进当前选中的游标；点击/拖动线选择目标，拖动交接同步目标，显式 index=0 仍可批量步进。
- 游标模式菜单使用互斥 ButtonGroup，禁止将当前模式取消勾选；主按钮仍负责启停。
- X 轴留白固定 22 像素，游标数字紧贴轴线，按实际宽度水平避让；去除 T1/T2 和 ΔT 文字前缀，空间不足时省略中间差值。读数只接收悬停，不阻挡轴框选。
- appcontroller_test 覆盖切换及稀疏样本视窗、独立原始样本步进、真实窗口选线及读数区域框选、重复点击菜单模式。
- 初始标签定位补修：Repeater 的 itemAt() 不会为 delegate 创建提供属性变更通知，布局曾沿用宽度为零的初值，导致读数右偏、差值隐藏。改为 itemAdded/itemRemoved 后延迟发布实际标签列表，位置及差值可见性使用此列表；新增首次开启、报告中的时间范围和重新开启回归，保证读数以游标线居中，宽间距下显示差值。

验证结果见本次任务报告；离屏窗口事件测试不等同人工 GUI 或真实 GPU 字体视觉验收。

## 示数直接操作

- 按用户后续要求，示数接收点击/拖动：时间选择对应游标，差值同时选择两个，方向键跟随选择；两条整体移动保持间距，更新在锁内原子发布。
- 两条线可见时差值不再按间距隐藏，三个示数水平避让；单游标或视窗内只剩一条线时隐藏差值。轴高度仍固定，示数去除悬停文字及特殊指针，其他轴留白仍可框选。
- 新窗口事件回归覆盖单/双目标选择、示数拖动、方向键整体步进、边界保持间距、重合及单线可见的差值显隐。

## 操作时自动选择子图

- 补齐时间图绘图区滚轮、X/Y 轴滚轮及轴框选的激活入口，空格自适应先激活操作所在子图。航迹适应及打开视角菜单也先激活。
- 两子图窗口事件回归覆盖各区域滚轮、轴框选、绘图区平移/框选、空格自适应；悬停不切换当前子图。
