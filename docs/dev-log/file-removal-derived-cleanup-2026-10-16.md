# 删除文件后的派生引用清理（2026-10-16）

用户截图：移除 MAT 文件后，信号树仍有合并及丢包检测输出，空子图仍有图例。

根因：removeFile 只删除原始行并把字段重映射到 -1，既有派生调度随后只清空结果数组。规则输出行仍存在于 SignalModel 和子图勾选集合，故信号树和 PlotLegend 仍展示空引用。

修复：按删除前的原始行号计算对象规则依赖闭包，移除直接与间接依赖此次文件删除的规则及全部输出；原始行与派生行统一删除并只做一次行号映射。取消旧任务，随后刷新保留子图和规则，防止旧结果重新发布。独立分支、已有其他诊断和对象字段配置保留。手动解绑字段的行为保持原有规则保留/可重绑语义；显式文件移除则级联删除相关规则，包括少了一个输入的合并规则。

验证：新增真实 QML PlotLegend 回归，覆盖同名路径隔离、多子图、合并和丢包检测及下游、独立分支、保存恢复、末文件删除与在途任务取消。待构建与测试完成后追加结果。未做人工 GUI、真实用户 MAT、Release 或 GPU 验证。
