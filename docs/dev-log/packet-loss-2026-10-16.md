# 丢包检测（2026-10-16）

需求：按相邻样本时间检测缺包，自动估算且允许手动修改周期，输出丢包率和累计数量。

实现：在对象规则中增加 packetloss，两条原始时间轴阶梯输出；使用有界中位数估算周期，按最近整数间隔累计缺失数，以收到点数和缺失数之和作为百分比分母。严格拒绝重复、倒退、非法时间及计数溢出。后台快照、取消、预算和下游失效复用现有机制。规则摘要显示有效周期，编辑自动结果时预填估算值。会话升级 v12，旧版读取保持默认值迁移。

## 自动建立默认对象与周期直接编辑

后续需求：每次导入文件创建默认对象、每组采样时间建立检测；移除自动估算勾选框，采样周期直接填入估算值。

最终实现：加载线程对时间数组做有界分块哈希和精确比较，同文件完全相同的时间轴共用检测，不跨文件合并；每组用一个原始代表信号，估算值随 LoadedTable 返回。默认对象在批量原始行安装后统一分配派生行并校验提交，再启动原有派生后台任务。超单对象上限拆分，超工作区对象上限则提示并保留原始导入。取消时为此前成功文件安装已暂存对象，失败文件不创建。

QML 只有可编辑的秒数框，打开/切换输入时预填估算周期，无法估算时留空提示。已保存数值不因导入或重算而覆盖；旧 0 值规则首次成功计算后转为实际周期并更新计算键。会话恢复不创建任何额外对象。CLI rule_update 支持 packetloss/samplePeriod，load 任务等待检测结束并单列诊断，原始导入成功不被检测失败掩盖。

验证：默认对象集成、周期数字预填与实际对话框、会话恢复、启动导入/拖放、导出和 CLI 回归已覆盖；最终构建/测试结果在下方追加。旧版 schema 和指定手工图测试显式构造不含默认对象的 fixture，未关闭产品功能。真实 GPU、人工 GUI、Release 和部署未验证。
