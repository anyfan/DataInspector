# 航迹旋转性能、拖动方向、双参数与布局（2026-10-02）

用户反馈旋转严重卡顿、水平拖动方向反转、不能只选两个参数、子图里航迹过小。

## 根因与改动

- 原旋转预览每次扫描全部原始样本、逐点计算三角函数；连续相机请求取消尚未完成的结果，拖动期间可能一直没有新画面。
- 后台一次准备归一化空间缓存与 Douglas–Peucker 分层索引，缺失段和端点独立保留。每预览一次计算矩阵与比例，只投影所选级别的原始样本索引。细节依空间误差选择，拖动对复杂路径限制约 16000 个预览点，释放后补精细结果。
- 相机变化合并请求而不取消有效来源任务，先提交匹配来源的中间画面，再处理最新相机；换来源或销毁仍取消旧任务。数据/索引/预览均为不可变快照，GUI 拖动和 SG 节点保持原有线程边界。
- 水平旋转改为 azimuth 减去水平鼠标位移，修正相反的拖动方向。二维模式左键平移。
- 空间 XYZ 任选两轴自动显示 XY/XZ/YZ 平面，三个轴才三维；经纬度须选纬度和经度，高度留空为水平航迹。留空轴不参与时间基验证、原始读数及导出，不产生虚构的零高度。会话 axes 的 -1 既有表达足够，v3 JSON 结构不变。
- 顶部改为单排坐标/视角/适应/时间图，底部为一行优先游标读数，悬停查看全部详情。绘图区含边框仅保留约 50 个逻辑像素给控件；320×240 子图的画布为 316×190。
- 改用当前投影边界共同适应画布宽、高，保持等比例和约 6% 边距，浅平航迹不再限定为短边的一半。

## 性能证据

同一 Debug 工具链、同一百万点模拟飞行路径、1200×800 画布、10 个视角预览：

| 项目 | 改前 | 改后 |
| --- | ---: | ---: |
| 初次后台准备 | 408.26 ms | 约 1993.49 ms |
| 平均单次旋转预览（投影 + 几何） | 459.81 ms | 1.41 ms |

改后复用索引，预览投影样本小于 10000。首次准备变重，用于换取后续交互速度；新增归一化缓存和分层索引也占用内存。数值是模拟数据的 CPU 预览成本，不是实际 GUI 帧率或用户实飞文件结果。

## 验证

Debug 构建与 qmllint 零 warning 通过。新增覆盖双参数三种平面、经纬度高度留空、会话恢复、原始读数不出现未选高度、左拖方向、二维平移、空间简化误差/尖峰/断线、百万点预览成本、持续相机请求仍提交画面、640×480 与 320×240 布局。

Windows D3D11 原生 QML 自动化确认三参数与两参数配置切换，截取三维和小子图二维航迹画面；硬件轨迹光栅检查通过。最终 CTest 11/11 通过（40.22 秒），`git diff --check` 通过。
