# CLI 能力发现、Windows 编码与批量枚举

针对实际使用反馈，增加线协议/API 版本和 schema 指纹发现，保持 help.result 数组不变，另在 help 外层、status 和连接描述文件提供 cli 元数据；能力命令同步公开命令名和限额。API 修订 2，线协议仍为 1。客户端显式期望版本/指纹时先预检，不匹配和旧服务无法发现能力时不发送修改；无预检选项不增加每条调用往返。

新增 --ascii，成功/失败 JSON 都可使用纯 ASCII 转义；文档说明 PowerShell UTF-8 解码与参数文件，以及乱码不等于存储损坏。

批量枚举使用一个 generation、最多 256 个唯一信号和严格枚举表；全部验证后整体替换控制器映射，仅刷新一遍状态视图。结果返回实际枚举和原始/显示名称，支持幂等重试。64 KiB 请求上限不变，每批独立原子提交。单项编辑复用此校验路径，会话 v22 和模板 v6 的持久结构不变。

工作流明确区分整值互斥状态和独立标志位：依据协议定义 bitfield 多输出，确认计算后发现输出编号，再批量加枚举。回归包含 98 项批量、非法末项不产生部分修改、单次通知、ASCII 中文往返、版本检查和实际位段输出数值。
