# 后台退出的保存提示

用户反馈程序在后台退出时看不到未保存会话提示，导致无法操作退出。原实现仅在主窗口内打开 Dialog，没有恢复或激活主窗口。

SessionDialogs 请求退出确认时发出 attentionRequested，Main 恢复隐藏/最小化的窗口并保持此前的普通/最大化/全屏状态，然后 raise/requestActivate；关闭事件处理后再次请求激活，且仅在退出决策仍待处理时执行，避免放弃后重新打开窗口。确认框显式使用 Overlay、焦点和顶层 z，保存选择器显式绑定主窗口；保存选择器已经打开时重复退出复用该选择器，不额外打开确认框。

扩展现有会话 QML 回归，覆盖最小化/隐藏窗口恢复、最大化状态保留、重复关闭、保存取消、放弃退出和无修改直接关闭。离屏后端不支持实际桌面 raise；另用 Windows 平台 + Qt Quick software 运行同一交互回归，创建前台干扰窗口并验证退出请求后主窗口 isActive，已通过。测试中的文件选择器设为非原生，避免本机测试进程原生文件选择插件崩溃；软件运行时的选择器设置不变。

验证：Debug 主程序构建、qmllint 零 warning、session_test 全套 13 项通过；Windows 平台的焦点/关闭交互回归通过。未进行 GPU 渲染验证或原生保存文件选择器桌面验收，未更新正在运行的 Release 程序。

后续按用户要求将未保存确认框设为 Popup.NoAutoClose：点击外部和 Esc 均不关闭，必须通过保存、放弃或取消按钮处理。扩展交互回归验证外部点击与 Esc 后提示及待退出状态仍保留。
