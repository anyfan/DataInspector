# 飞机辨识度与姿态表单显示修复（2026-10-02）

基线 66e9bcc，工作区开始时干净。用户截图反馈飞机与航迹难区分且偏大，姿态对话框有字段/下拉显示问题。

## 改动

- 模型固定比例由 22 改为 14 逻辑像素，约缩小 36%；改为窄机身、后掠双翼、水平/垂直尾翼六个面，保持原 FRD→NED 测量及相机投影链。
- 浅色机身、与航迹颜色相区分的机翼填色、白色外沿及深色细描边，使姿态模型在白/深背景及曲线交叉处更清楚。SG 继续使用不可变几何和 Qt 内置材质。
- 有姿态的游标点从 8 缩至 3 像素，文字移至模型右侧 24 像素，避免中心圆点/文字盖住机身；无姿态标记保留原样。
- 样式表单独立显示名称、颜色、线宽标签；紧凑行高，长来源名称中间省略，选项及控件悬停显示完整名称。
- 显式 PropertiesCombo 委托处理字符串和对象模型，两个欧拉顺序选项均显示文字。ScrollView 使用明确的 Flickable/contentHeight，约束表单宽度，溢出时常显纵向滚动条；重开从顶部显示，底部操作按钮独立于滚动区域。

## 验证

Debug 构建、DataInspector_qmllint 零 warning；相关 trajectory_test/rendercore_test/appcontroller_test/session_test 通过。源码和编译 QML 在 Windows 原生窗口验证表单、两个旋转顺序选项、滚动下方方向设置、重开复位；保存表单/下拉截图用于视觉检查。

D3D11 光栅验证通过：模型测得约 29.14×13.14 逻辑像素（此测试视角），深色描边 375 个物理像素，尺寸上界检查 42 逻辑像素；测量航向变化及缺失样本隐藏继续通过。尺寸会随姿态/观察方向投影改变，但不随航迹缩放改变。

初次委托文字测试使用 QObject 所属关系无法找到 ListView 的视觉委托，随后改为 childItems 视觉树查询；不以控件 displayText 代替实际下拉选项检查。
