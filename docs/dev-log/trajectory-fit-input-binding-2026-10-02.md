# 航迹自适应、鼠标路由与绑定（2026-10-02）

用户报告偶发仿真 `(0,0)` 位置拉偏整体自适应、中键像平移、滚轮未以鼠标位置缩放，以及轴绑定不易使用。用户明确 `(0,0)` 只应排除出自适应。

- 经纬度的自适应中心和边界忽略同时为零的位置，投影原点优先使用非零有效定位；原始样本、连线、游标和导出全部保留。仅一个坐标为 0、普通 XYZ 零点不受影响，全部为零时有有限范围回退。
- 航迹画布统一接收左/中/右键及滚轮，显式转发同一 C++ 交互逻辑，禁止拖拽被其他层接走。左键平移、中键旋转，二维不旋转。按新旧缩放比修正平移，锁定滚轮鼠标锚点。
- 顶部三轴按钮显示实际来源：点击轴再从树选择可替换，跨轴选择已有来源则交换；右键清空。经纬度按原始/显示名识别 lat/lon/alt 角色，未识别时补空轴。临时替换目标不写会话，格式仍为 v4。
- 新增零定位自适应/样本保留、首点零定位、全零/单零/普通 XYZ、鼠标锚点、轴替换/交换/取消、经纬度反序选择回归；窗口级 QML 事件测试检查中键、左键和滚轮完整路由。

验证：Debug 完整构建及 qmllint 零 warning 通过。8 个相关 CTest 套件全部通过，轨迹套件含窗口级鼠标、零定位、自适应与绑定回归。Windows 原生 D3D11 的四项重点轨迹用例通过（含真实窗口事件路由），等轴测/俯视/自由旋转光栅检查通过，640×480 与 320×240 画布尺寸保持。轴按钮由 Repeater 生成，测试改为查询视觉树以定位按钮；初次 QObject 所有权树查询失败，修正后通过。人工实际飞行数据、鼠标手感、Release 与部署未验收。
