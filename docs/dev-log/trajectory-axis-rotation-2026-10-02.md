# 航迹中心旋转与轴约束

日期：2026-10-02。

## 问题与改动

原拖动以屏幕位移构造倾转轴，无法明确约束到空间 X/Y/Z，也没有可见的中心参考。

- 自由模式改用虚拟轨迹球，短边 45% 半径，球面外平滑接双曲面；小坐标轴作为球心拖动手柄。
- 三维画布右下角新增自由/X/Y/Z 选择。轴约束使用固定世界轴，方向不随相机改变。
- 轴模式左键旋转，Shift+左键平移；自由模式保留左键平移、中键和小坐标轴旋转，并增加 Alt+左键。
- 旋转中显示绘图区中心圆环、十字及文字。投影比例固定，平移和深度偏移随旋转同步变换，中心保持固定。
- 拖回按下点恢复方向与位置。二维隐藏模式控件，保留轴选择也不影响左键平移。
- 模式选择仅是子图交互状态，会话版本与格式不变。

实现涉及 `trajectoryitem.*`、`TrajectoryPlot.qml`；用户手册、架构与测试文档同步更新。
