# 飞机位置投影与方向坐标轴

用户用纬度、经度和高度观察飞行位置。旧空间 XYZ 模式直接将度和米共用比例，水平航迹被高度变化压缩成近似竖线。

- 增加经纬度/高度坐标类型，明确输入纬度（度）、经度（度）、高度（米）。WGS84 椭球表面 ECEF 差值投影到首个有效位置的东/北切平面；Z 单独使用记录高度差，不引入曲率下沉。
- 缓存不可变米制坐标，旋转时复用；Store、原始样本游标查询、经纬度/高度读数和导出值保持原样。角度超范围明确报错，缺失点断线。
- 移除外部包围框，以红 X、绿 Y、蓝 Z 的固定大小角落坐标轴显示当前旋转；平移/缩放不会移动该坐标轴。
- 会话 v3 增加必填 geographic 布尔值，兼容 v1/v2。配置对话框显示坐标含义，窗口较小时可以滚动，确认按钮固定可见。
- 无新增绘图库、地图 SDK 或网络数据依赖；只适合局部飞行区域的平面投影，不提供全球航迹测距或高度基准转换。

Debug 完整构建、QML 零 warning、CTest 11/11（27.23 秒）及 Windows D3D11 原生 QML 配置/渲染通过。新增测试覆盖米制量级、方向、首个有效原点、跨日期线、近极点、越界输入、缺失样本、模式切换缓存、原始读数、小坐标轴旋转与平移/缩放独立性、v1/v2/v3 会话。窗口尺寸限制和滚动配置接入后，控制器/会话/启动拖放/轨迹 4/4 回归通过（17.06 秒），qmllint 零 warning；640×480 原生配置对话框与轨迹截图验证通过。硬件轨迹光栅测试也通过。

未进行用户实际飞行文件验证、手工 GUI 验收、Release 构建、部署或大型数据帧率基准。
