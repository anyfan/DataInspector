# 子图菜单、状态短脉冲与运行中 CLI · 2026-10-20

本文记录当次实现与验证，不作为后续需求。现行行为见用户指南及架构文档。

## 改动

- 状态图的状态行管理／前后变化定位，以及航迹图的配置／视角／适应操作移到对应右键菜单。曲线、状态和航迹共用 Fusion 菜单组件；隐藏项同时归零高度，修复菜单中间或底部留白。二维航迹隐藏三维视角子菜单。
- 状态区间按屏幕桶中点采样时，跨桶短脉冲可能同时避开两侧中点，导致压缩标记随缩放消失。现在检查相交的、两端均有实际切换且短于桶宽的完整区间，保留紫色标记；进一步放大后恢复枚举色，普通阶跃及记录边缘不按短脉冲误标。
- AppController 持有 CLI 服务，启动参数和设置对话框共用同一实例。运行中开启自动生成当前用户临时目录中的 UUID 连接文件；支持复制路径／PowerShell 命令、关闭及重新开启。关闭清理自身文件，重新开启更新令牌和 epoch；已提交的控制器操作不回滚，工作区及会话修改状态保留。
- 新增 `AutomationDialog.qml`、`appcontroller_cli.cpp` 和共用菜单组件，更新 CMake 列表；构建后复制 `datainspector_cli.py` 到 exe 旁边。会话／模板版本保持 v22／v5，未调整发布版本号。
