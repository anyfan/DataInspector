# Agent 工作流增强与共享合并时间线

需求来自两次实际 CLI 任务：新飞管文件的飞机航迹遗漏姿态、log_335 的大量同源信号需要清空/重载和批量合并。用户要求落实改进，明确排除 MCP。本次仅扩展已有本机 CLI 和共用控制器，不添加 Python SDK、远程服务或文件名特判。

## 交付行为

- 修改及异步命令有统一任务 ID、进度、时间、实际结果、错误与协作取消；CLI --wait 按最终状态退出，支持按 ID 恢复等待。requestId 对相同命令/参数重用原任务，对参数冲突明确拒绝；内存保留有界，进程退出后失效。
- 命令发现与校验共用 commandcatalog，包含参数/返回/任务结果 schema、类型、必填、枚举、范围与默认值。CLI 超时保留已知任务 ID，后台操作不会因客户端超时自动撤销。
- aircraft_setup 一次校验配置与全部绑定，保留已有字段名称和身份；aircraft_check 分开报告位置、姿态、单位声明、坐标约定、视图和游标模型状态。可复用 version=1 映射模板支持别名/正则/来源限定、歧义及单位不兼容拒绝。
- merge_preview 实际校验原始样本，返回版本化计划、冲突、输出样本数、已有来源规则和内存估算；merge_execute 只提交有效且未过期计划，跳过已有规则，同一计划重复执行不增加定义。规则可按稳定 ID 更新、取消后重算。
- 信号树提供可逆逻辑结果视图；对象规则按名称/来源/错误搜索、状态筛选、每页 20 条并有汇总。成功合并替代原始输入的显示，失败保留来源。
- export_logical 输出 MAT/XLSX 与 manifest.json，记录逻辑列、全部原始来源、对象/完整规则、样本数和时间偏移；临时目录完整写入后发布，不覆盖现有目标。
- MergeTimelineCache 只在单次规则计算内复用相同不可变时间数组/偏移的排序与并集，64 MiB 驻留上限，保留逐列缺失/冲突检查与原始精确时间语义。未改 Plot LOD 或渲染锁。

会话保持 v11；任务、合并计划和逻辑显示开关为运行期状态。单位声明不触发数值换算，也不能从信号名证明物理单位。对象绑定事务不包含随后视图和游标操作；后者失败时返回已提交事实。
