## 已修复的问题

### 1. 恢复会话后继续导入可能越界

`finishSessionRestore()` 原来将 `m_nextColorIndex` 直接设为信号数量。调色板只有 14 个颜色，当恢复 14 个或更多信号后继续导入，`signalPalette().at(m_nextColorIndex)` 会越界：Debug 可触发断言，Release 存在崩溃风险。

现在按调色板长度取模，新增信号从现有信号数量对应的循环位置继续取色，已恢复的自定义颜色和线宽不变。

回归覆盖：14、15、31 个信号的保存/恢复，随后再导入两个信号并核对颜色；也核对原信号的自定义样式未被改写。

### 2. 大时间戳、极窄范围的刻度与标签

原刻度计算将绝对刻度索引经 `qCeil` / `qFloor` 转为整数。Unix 时间戳配合小步长就可能超过整数范围；亚正常数步长还可能下溢成零。固定 12 位标签精度也可能让不同刻度显示同一个数。

- 新增独立的 `render/plotaxisutils.h/.cpp`，把刻度与适应边距逻辑从绘图项中提取出来。
- 用浮点起点和最多 12 次局部步进生成刻度，不把绝对刻度索引转换为整数。
- 保证刻度有限、在范围内且严格递增；无法形成规则网格时使用端点。
- 常规标签保留原来的紧凑精度，发生重名时逐步提升至最多 17 位有效数字。
- QML Y 轴保留普通范围的紧凑格式；若多个刻度格式化后相同，则使用后端精确标签，轴宽测量也使用同一套标签。
- 自动适应使用有限且可表示的边距，极大常数不会因加减 0.5 被舍入为同一个数；不再用相对模糊比较把大基数上的有效时间跨度误判为常数。
- 不可表示的跨度不写入绘图项或共享 X 缓存。初次导入也不提前修改缓存，避免随后保存会话因范围非法而失败。

已先运行新增刻度回归：修复前 `axisTicksHandleLargeAndTinyRanges` 失败，原有测试仍通过。修复后覆盖正负 Unix 时间、大基数窄视窗、亚正常数、正常范围、极大常数和真实 QML Y 轴标签。

跨度大于 `double` 可表示范围时保留原视窗，并不声称可在一个线性视窗中完整显示这类数据。

### 3. LOD 分桶的浮点转整数风险

原实现先把 `(x - xmin) / bucketWidth` 转成 `int`，再截断到桶范围。远处的连接点可能使商溢出，极窄视窗可能使桶宽下溢为零；两者都让整数转换不安全。

现在先在浮点域判断左右边界，对视窗内的点使用归一化比例，再把已限定范围的结果转成整数；拒绝跨度溢出的请求。采样下标使用 `qsizetype`，绘图项像素宽度也在整数转换前限定。

回归覆盖极远连接点和亚正常数窗口，保留两端样本；原有极值顺序、NaN 断线及邻接点测试继续运行。

## 已完成的优化

### 4. 乱序序列时间范围查询复用摘要

原 `PlotSeriesStore::timeBounds()` 对乱序序列每次逐点扫描，适应 X 轴和验证时间偏移都可能在 GUI 线程重复做这项工作。

- 后台已有的索引构建循环额外记录原始时间最小/最大值，不增加一次全量遍历。
- 时间摘要独立于 Y 的有效性；即使所有 Y 都是 NaN，有限的时间仍参与适应范围。
- 正常的索引化序列只读取一份摘要，并施加当前时间偏移，复杂度为每条信号 O(1)。
- 无索引的旧式手工快照保留兼容查询路径；异常偏移使摘要端点溢出时使用有限样本回退路径。
- 时间偏移与画笔修改继续共享原始数组和同一个范围索引。

确定性测试结果：

| 场景 | 原始样本扫描 | 摘要访问 |
| --- | ---: | ---: |
| 100 万点乱序序列，索引查询 | **0** | **1** |
| 同一序列的无索引兼容路径 | **1,000,000** | 0 |

该结果是工作量计数，不是未经测量的端到端加速倍数。原有百万点窗口 Y 范围测试仍只扫描 574 个边缘样本、访问 15 个索引节点。

### 5. 相同画笔不再使 LOD 失效

- 按现有 ID → 位置哈希定位信号，不再线性搜索并重建整张位置表。
- 颜色、线宽、线型未变时直接返回，保留快照指针和数据代际。
- 真正修改时只替换目标信号的不可变快照，旧快照、原始数据及范围索引仍安全共享。
- 控制器在仓库代际未变化时不再刷新子图绑定和图例。

回归覆盖连续 100 次同值设置、未知 ID、真实修改、复制仓库后的写时分离，以及控制器同值设置不发出 `plotBindingsChanged`。

## 后续值得单独推进的工作

- 非单调时间的游标最近样本查询仍可能扫描原始数组。引入排序索引需要保留重复时间和等距离时的原始顺序语义，并评估索引内存成本。
- 本轮不重写 LOD 的取点算法；现有乱序曲线按视窗滤点的策略，其跨边界折线连接需要专门的算法级回归。多级 LOD 缓存和内存预算也应单独设计。
- 大型真实 CSV/MAT 性能测试需要显式提供测试数据环境变量；默认回归不会执行这些可选基准。GPU 驱动上的实际交互/帧率仍需专门验收。
