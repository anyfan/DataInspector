# Qt Quick 游标、坐标轴、图例与多子图迁移设计

## 背景与目标

当前 Qt Quick 分支已经提供 `PlotItem`、CSV/MAT 加载、信号选择和基础单游标，但坐标轴、图例和多子图仍停留在旧版 QCustomPlot 实现或尚未迁移。此阶段建立一套不依赖 QCustomPlot 的可复用视图状态，并按“完整游标 → 坐标轴 → 多子图”的顺序迁移，使后续功能不再直接修改 Scene Graph 节点之外的渲染状态。

## 范围与顺序

1. 完整游标：无游标、单游标、双游标；原始数据点吸附；每条可见曲线的原始样本 Y 值；Y 标签原始/精简格式切换；双游标的 ΔT。
2. 坐标轴和网格：X/Y 刻度、边界标签、格式化精度、网格线，并与 `PlotItem` 的视图范围同步。
3. 多子图：每个子图独立信号集合和 Y 范围，X 范围可同步；激活子图决定游标拖动和吸附来源。
4. 图例逻辑贯穿以上三步：信号选择、颜色、名称和目标子图变化时立即更新；图例点击切换可见性，图例布局支持顶部流式排列、内嵌左上/右上和隐藏三种模式。

本阶段不迁移重放、Python API、图片导出或 `.mldatx`/JSON 视图文件。

## 设计

### 视图状态与数据接口

`PlotItem` 保持现有 `setSeries`、`appendSeries`、`clearSeries` 和范围属性兼容，并新增只读的系列元数据访问和游标结果信号。游标计算使用原始序列而非 LOD 序列，不进行插值：对单调时间序列二分查找距离最近的原始时间点；非单调或含无效时间时遍历可用点寻找最近时间。游标状态保存两个数据 X 值和每条系列的显示格式标记，视图平移/缩放不重置游标。

坐标轴和网格作为 `PlotItem` 的轻量 QQuick 子项或同一 `QSGNode` 根节点的独立层实现，所有像素位置由同一个 `ViewTransform`（X/Y 最小值、最大值、尺寸）计算。坐标轴只读 `PlotItem` 的范围，不在 QML 中复制缩放公式；范围变更通过已有 `rangeChanged` 信号传播。

图例由 `SignalModel` 提供名称、颜色、checked 和所属子图索引。QML 图例 delegate 只负责布局和点击，点击通过 `AppController` 修改信号选择；控制器再把同一结果分发给各 `PlotItem`。颜色由控制器为每个逻辑信号稳定分配，切换子图或重载文件时不改变同一加载会话中的颜色。

### 游标交互

- 工具栏提供“关闭游标、单游标、双游标”互斥选项；启用时单游标默认位于当前 X 范围 5% 处，双游标第二条位于 95% 处。
- 鼠标靠近游标线时进入拖动状态；拖动位置限制在当前 X 范围，并按当前激活子图的原始数据点吸附。
- 单游标和双游标都在所有子图同时可见；每个子图显示相同 X 位置的游标线，并显示该子图每条可见曲线的同色 Y 标签。标签重叠时按屏幕 Y 排序并向下错开，超出边界时保持在子图可视区域内。
- 点击 Y 标签切换精简格式（`g`）与原始十进制格式（最多 12 位、去除尾零）。双游标模式只在 X 轴区域显示带符号 ΔT，不显示 ΔY。
- 无有效数据或游标所吸附的原始样本为 NaN 时不绘制该系列的 Y 标签；游标本身仍可移动。

### 坐标轴与图例

刻度生成使用“1/2/5 × 10^n”步长，目标每个方向 5–9 个主刻度；刻度文本根据步长选择固定或科学格式，避免重叠时降低到较少刻度。网格线使用与主题适配的低透明度材质，不参与数据 LOD。

图例默认显示在每个子图顶部；窄于可用宽度时按流式布局换行。图例项包含颜色标记和信号名，点击项只切换该信号在所属子图中的可见性，不改变原始数据。图例隐藏时不占布局空间；信号列表仍是全局选择入口。

### 多子图状态

控制器维护 `PlotBinding`：目标 `PlotItem`、信号 ID 集合、Y 范围策略和 X 同步标记。`setLayout` 重建绑定时保留已加载数据和全局信号选择；每个子图初始绑定当前已选信号，随后允许图例点击在单个子图内切换。所有子图共享 X 范围时，任一子图的 X 拖动/缩放传播到其余子图；Y 范围默认独立并由绑定信号自动适配。

## 错误处理与兼容性

- 空数据、全 NaN 系列、单点序列必须保持可渲染且不触发除零；轴范围回退到 `[0,1]` 和 `[-1,1]`。
- 文件加载线程、MAT 变量命名和现有 `SignalModel` 行号接口保持不变。
- 所有 UI 文本继续使用“游标”“坐标轴”“图例”和“信号”，不引入旧版 QCustomPlot 类型。
- 不能在渲染线程访问 QObject；计算结果通过值类型快照和 Qt 信号传递。

## 验证与验收

- 本阶段只要求 Qt 6.8.3 LLVM-MinGW 配置下 Release 或 Debug 构建成功；不把 offscreen 启动、人工 GUI 回归或性能测试列为完成条件。
