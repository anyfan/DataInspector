# 视图操作

## 基本交互

- **拖动**：绘图区按住左键拖动平移。
- **滚轮**：在绘图区上双轴缩放；悬停在 X 或 Y 轴刻度区时，滚轮只缩放对应轴，且以指针所在数据值为中心保持不动。
- **框选缩放**：在轴刻度区按住拖动拉出矩形，缩放到该范围。
- **空格**：鼠标在绘图区时按空格，自适应当前子图 Y 轴；悬停在轴区时按空格同时适应该子图 X/Y。

## 自适应

首次添加信号自动适应共享 X 轴和对应子图 Y 轴；后续增删信号只重新适应受影响子图的 Y，保留 X 范围。

| 操作 | 快捷键 |
| --- | --- |
| 自适应当前视图 X/Y | `Ctrl+Alt+F` |
| 自适应全部视图 X/Y | `Ctrl+Alt+Shift+F` |
| 自适应当前时间轴 | `Ctrl+Alt+T` |
| 自适应全部时间轴 | `Ctrl+Alt+Shift+T` |
| 自适应当前 Y 轴 | `Ctrl+Alt+Y` |
| 自适应全部 Y 轴 | `Ctrl+Alt+Shift+Y` |
| 回退视图修改 | `Ctrl+Z` |
| 全屏 / 退出全屏 | `F11` |

- 时间轴在所有子图间共享。"当前/全部"决定参与计算范围的信号集合。
- 子图最大化时，自适应范围以该子图为准，不并入其他子图。
- Y 轴适应基于当前 X 窗口内的数据；空图恢复默认范围。
- 非归一化视图中，若窗口内信号为非零常量，Y 轴按常量绝对值的 5% 留白；零常量使用 `[-0.5, 0.5]`。

## 刻度与数值显示

- X/Y 刻度密度随绘图区尺寸调整，同列子图统一 Y 轴留白。
- 大数值/微小数值自动用科学计数法；相邻标签因舍入重复时自动增加精度。
- 零刻度精确显示 `0`，不出现 `-2.08e-17` 这类浮点残差。

## 游标

- 工具栏切换单/双垂直游标；子图间游标位置同步。
- 开启时在当前 X 范围的 25% / 75% 处按该图原始样本吸附初始化。
- 拖动游标时两根游标互不穿越；拖过对方时自动交接。
- 显示原始样本读数和 ΔT；游标工具开启时，`←` / `→` 在相邻原始样本点间步进。
- 归一化视图中游标仍显示原始 Y 值。

## 视图回退

`Ctrl+Z` 回退缩放、框选、平移、自适应、Y 轴归一化，最多 100 步；一次完整拖动合并为一步。在文本编辑框中 `Ctrl+Z` 仍是文本撤销，不回退视图。

回退范围**不包括**文件导入/移除、信号绑定、重命名、画笔或时间偏移。改变布局、清空全部数据或成功恢复会话时清空历史。

## 重叠曲线层级

默认启用"小幅值曲线优先置顶"（子图右键菜单 → 设置）：按当前可见区间内 `mean(abs(y))` 排序，大幅值画在底层、小幅值画在顶层，保留原色。点击选中的曲线额外置顶。关闭后按原始绘制顺序覆盖。详见 [渲染管线](../architecture/render-pipeline.md)。

## 高亮与图例

- 单击曲线或图例：高亮对应图例、在信号树中定位、并把该曲线置顶。
- 拖动图例可跨子图移动信号；图例右键可从当前子图移除信号。
- 子图右键菜单提供"自适应当前 Y 轴"和"清除当前子图所有信号"。
