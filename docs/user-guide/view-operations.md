# 视图操作

> **状态**：现行 · **读者**：最终用户 / AI 代理 · **关联代码**：`plotitem.*`、`qml/QuickPlot.qml`、`appcontroller_plots.cpp`、`render/plotaxisutils.*`

## 基本交互

- **拖动**：绘图区按住左键拖动平移。
- **滚轮**：在绘图区上双轴缩放；悬停在 X 或 Y 轴刻度区时，滚轮只缩放对应轴，且以指针所在数据值为中心保持不动。
- **框选缩放**：在轴刻度区按住拖动拉出矩形，缩放到该范围。
- **空格**：鼠标在绘图区时按空格，自适应当前子图 Y 轴；悬停在轴区时按空格同时适应该子图 X/Y。

## 自适应

首次添加信号自动适应共享 X 轴和对应子图 Y 轴；后续增删信号只重新适应受影响子图的 Y，保留 X 范围。

| 操作 | 快捷键 |
| --- | --- |
| 自适应当前视图 X/Y | `Ctrl+Alt+F` |
| 自适应全部视图 X/Y | `Ctrl+Alt+Shift+F` |
| 自适应当前时间轴 | `Ctrl+Alt+T` |
| 自适应全部时间轴 | `Ctrl+Alt+Shift+T` |
| 自适应当前 Y 轴 | `Ctrl+Alt+Y` |
| 自适应全部 Y 轴 | `Ctrl+Alt+Shift+Y` |
| 回退视图修改 | `Ctrl+Z` |
| 全屏 / 退出全屏 | `F11` |

- 时间轴在所有子图间共享。"当前/全部"决定参与计算范围的信号集合。
- 子图最大化时，自适应范围以该子图为准，不并入其他子图。
- Y 轴适应基于当前 X 窗口内的数据；空图恢复默认范围。
- 非归一化视图中，若窗口内信号为非零常量，Y 轴按常量绝对值的 5% 留白；零常量使用 `[-0.5, 0.5]`。

## 刻度与数值显示

- X/Y 刻度密度随绘图区尺寸调整，同列子图统一 Y 轴留白。
- 大数值/微小数值自动用科学计数法；相邻标签因舍入重复时自动增加精度。
- 零刻度精确显示 `0`，不出现 `-2.08e-17` 这类浮点残差。

## 当前子图

对某个子图执行滚轮缩放、平移、绘图区或轴框选、空格自适应时，会自动将该子图设为当前子图；信号树选择和后续工具栏操作跟随切换。航迹的旋转、平移、缩放及“适应/视角”操作同样选择该子图，单纯悬停不会切换。

## 游标

- 工具栏选择单/双垂直游标模式后立即开启该模式；模式选项互斥且不能同时取消，主按钮关闭或重新开启上次选择的模式；子图间游标位置同步。
- 缩放下拉菜单选择区域/X 轴/Y 轴模式后立即启用；主按钮关闭或重新开启上次选择的缩放模式。
- 开启时在当前 X 范围的 25% / 75% 处按该图原始样本吸附初始化。
- 拖动游标时两根游标互不穿越；拖过对方时自动交接。
- 单游标切换双游标保留 T1，新 T2 在当前视窗内初始化并选中；无视窗内样本时保留视窗内时间位置，读数仍取最近原始样本。
- 显示原始样本读数和时间差；点击游标线或 X 轴时间示数选择单个游标，拖动示数也移动对应游标，`←` / `→` 步进当前目标。
- 点击中间差值同时选中两条游标，拖动和方向键将它们整体移动，保持时间差；两条均在视窗内时整体移动到边界停止。
- X 轴留白固定，数值紧贴轴线，红蓝边框区分游标，选中边框加粗。两条游标可见时差值始终显示，三个示数水平避让，窄视图省略过长数字；单游标或仅一条线可见时隐藏差值。示数无悬停文字及鼠标图标变化，示数区域拖动游标，轴留白其他区域仍可框选。
- 归一化视图中游标仍显示原始 Y 值。

## 视图回退

`Ctrl+Z` 回退缩放、框选、平移、自适应、Y 轴归一化，最多 100 步；一次完整拖动合并为一步。在文本编辑框中 `Ctrl+Z` 仍是文本撤销，不回退视图。

回退范围**不包括**文件导入/移除、信号绑定、重命名、画笔或时间偏移。改变布局、清空全部数据或成功恢复会话时清空历史。

## 重叠曲线层级

默认启用"小幅值曲线优先置顶"（子图右键菜单 → 设置）：按当前可见区间内 `mean(abs(y))` 排序，大幅值画在底层、小幅值画在顶层，保留原色。点击选中的曲线额外置顶。关闭后按原始绘制顺序覆盖。详见 [渲染管线](../architecture/render-pipeline.md)。

## 高亮与图例

- 单击曲线或图例：高亮对应图例、在信号树中定位、并把该曲线置顶。
- 拖动图例可跨子图移动信号；图例右键可从当前子图移除信号。
- 子图右键菜单提供"自适应当前 Y 轴"和"清除当前子图所有信号"。

## 游标精确输入

双击 X 轴下方的 T1、T2 或 ΔT 示数，输入秒数（支持科学计数法）。Enter 或“应用”提交，Esc 或“取消”保留原位置；空值、NaN、Inf 和千位分组符不接受。

T1/T2 定位最近原始样本，实际时间以轴下示数为准。ΔT 固定 T1，将 T2 定位到距目标时间最近的原始样本，因此实际间隔可能与输入略有差别。目标在视窗外时，时间视窗平移到落点附近，跨子图继续同步。

T1/T2 分别编辑，不提供保持双游标间隔选项；原有点击差值选择双游标并整体拖动或步进的操作继续保留。
