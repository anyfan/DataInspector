# 导出 PNG 图片

工具栏的导出菜单提供“PNG · 当前子图”和“PNG · 全部子图”，选择保存路径即可。输出包含时间曲线或航迹、坐标轴、图例、游标及读数，不包含信号树和工具栏。

- 默认以窗口逻辑尺寸的 2 倍输出，尺寸不随 Windows 显示缩放再次放大；单边上限 8192 像素，超限时缩小窗口再导出。
- 当前子图是最近操作或选中的子图。全部子图按当前行列布局平铺，即使当前最大化了某个子图；完成后恢复最大化显示，不改变会话中的最大化配置。
- 保留当前主题、曲线样式和视图范围。导出前等待曲线/可见航迹后台准备完成，最多约 5 秒，超时报告失败。
- 导出进度旁的取消按钮可取消；失败和取消保留已有目标文件。
- PNG 是位图，没有矢量导出、自定义纸张或独立打印排版。准备图片期间请保持窗口打开。
