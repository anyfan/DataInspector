# 信号树与曲线样式

> **状态**：现行 · **读者**：最终用户 / AI 代理 · **关联代码**：`signalmodel.*`、`signalmetadata.*`、`qml/Main.qml`

## 信号树结构

左侧面板按 **文件 → `pN` 数据表 → 信号** 分层展开。信号行从左到右：勾选框、名称、线型预览。

信号行统一左对齐，不随层级增加缩进。文件行、数据组标题和滚动导航使用统一的平直浅底色、文字色、常规字重及行高；文件与分组的展开箭头和名称对齐，不使用圆角块、左侧竖条或链接下划线。嵌套组显示文件内的完整路径（如 `p2 / navigation / position`），悬停可查看包含文件名的完整路径。组仍可独立展开、折叠。滚动时顶部用单行面包屑导航显示当前层级（如 `flight.mat › p1`）；深层路径同样只占一行，过长的路径段中间省略，悬停显示完整路径。导航在列表上方留出独立空间，不遮挡信号行。

- **勾选框**：把该信号画到当前活动子图。
- **单击线型预览**：直接打开线条属性对话框（颜色、线宽、实线/虚线/点线/点划线）。
- **右键信号**：重命名…、时间偏移…、线条属性…。
- **右键数据表/文件**：时间偏移…（作用于其下全部信号，包括未勾选和被搜索隐藏的）。
- **右键文件**：移除该文件。

## 搜索

信号树顶部搜索框按名称忽略大小写匹配，命中关键词加粗着色。滚动时顶部导航显示“文件 › pN”祖先路径，单击某段路径回到对应行，双击该段折叠对应组。

## 隐藏面板

面板顶部直接显示搜索框，不再重复显示“信号 · 子图”标题或已加载文件摘要。搜索框右侧的“‹”可隐藏面板；通过“设置 → 显示信号树”恢复。隐藏不清除绑定和搜索状态。

## 重命名

右键信号 → "重命名…"。新名去掉首尾空白，空名被拒绝。重命名只影响显示名、图例和导出表头，**不修改源文件**；会话恢复后保留。

## 时间偏移

右键信号/数据组/文件 → "时间偏移…"，输入相对原始时间的偏移秒数：

- 正值向右、负值向左；对话框直接显示并修改为目标值，不重复累加。
- 组/文件作用于其下全部信号；组内偏移不一致时显示混合状态，输入新值统一设置。
- 偏移影响所有子图、游标读数、自适应范围和导出；不修改源文件。
- 视窗不自动跳转，可用"适应 X"查看平移后的完整范围。
- 加载或导出期间不能修改偏移。
- 会话保存后可保留；直接重载程序不保留。

## 颜色与线型

- 默认使用固定 14 色调色板，跨文件按顺序循环分配；清空后重置。
- 每信号独立设置颜色、1–20 px 线宽、实线/虚线/点线/点划线；图例同步显示。
- 信号属性对话框提供同一组预设色块。
- 相同画笔设置不会触发 LOD 重建。

## 清除信号

- "设置 → 清除所有信号"：解绑所有子图上的信号绑定，**保留已加载数据**。
- 子图右键 → "清除当前子图所有信号"：只解绑该子图。
