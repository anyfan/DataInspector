# 关于与构建信息

点击主窗口工具栏的“设置”→“关于”，打开关于页面。页面随浅色/深色主题显示，Esc 或“关闭”按钮可关闭。

“构建信息”展示版本号、构建时间（北京时间，UTC+8）、完整 Git hash、分支、构建时工作区状态、Debug/Release 类型、运行时 Qt 版本、构建架构和 MAT 支持状态。时间显示与复制均固定为北京时间，不随电脑时区改变。文字可以选中，“复制构建信息”可将全部字段复制到剪贴板，便于反馈问题。

版本号来自 CMake 项目版本；构建时间表示源码、构建配置或 Git 信息变化后采集的时间，并非程序启动时间。没有这些变化时重复构建保留原时间。Git hash 对应源码提交；如果工作区有未提交修改，该构建包含的代码可能超出该提交。源码包没有 Git 元数据时，页面明确显示“不可用”和未知状态。

“更新记录”显示随构建打包的[更新记录](changelog.md)，无需网络。当前版本为 0.1.0，日期条目为用户功能摘要，同版本的具体源码应结合 Git hash 与工作区状态判断。
