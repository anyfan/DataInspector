# 数据格式

## CSV / TXT

```text
Time,Signal A,Signal B
0.0,1.2,4.5
0.1,1.4,4.1
```

- 第一行必须是表头，至少包含时间列和一个信号列。
- 自动识别逗号、分号和制表符；支持单行内带引号字段和 `""` 转义。
- **不支持跨行引号字段**。引号格式错误的行跳过；表头引号错误则中止导入。
- 每行列数应与表头一致；错误行跳过。
- 时间无法解析的行跳过；信号值无法解析时记为 `NaN`，图上断线。
- 数值统一按 C locale 解析：小数点用 `.`，**不接受千位分组符**。`1,234` 不会被读作 1234，加不加引号行为一致。

## Excel XLSX

- 读取全部有效工作表，每张表作为一个数据表，信号树按"文件 → 工作表 → 信号"分组。
- 第一行表头、第一列时间、其余列信号；空单元格/非法值记为 `NaN`。
- 支持共享字符串、内联字符串和公式缓存值；**不会重新计算公式**。
- 仅支持 `.xlsx`，不支持旧版 `.xls`。

## MATLAB MAT（可选，`ENABLE_MAT=ON`）

识别文件中名为 `p1`、`p2`… 的非空、稠密、二维实数 `double` 矩阵：第一列时间，其余列信号。`pN_title` / `pN_title2` 作为列名。复数、稀疏矩阵、空矩阵跳过，文件中其他有效 `pN` 继续读取。

## 导出 Excel

"导出数据"菜单可选：

- **全部已加载数据** / **当前所有子图已绘制的信号**（后者合并所有子图信号，同一信号只导出一次）。
- 每个来源表独立工作表；第一列 `Time`，其余列为信号，`NaN` 写为空单元格。
- 不复制样式、公式、批注。
- ZIP 压缩默认开启，可在菜单中取消。
- 单表超过 1,048,575 行时自动拆分工作表。
- 后台导出，进度条旁可取消；目标文件仅在完整写入后替换。

## 导出 MAT

- 写出 MATLAB Level 5 文件，布局与导入一致：每个来源表一个 `pN` 二维 `double` 矩阵，以及 `pN_title` UTF-8 字符矩阵（第一行 `Time`，其余为信号显示名）。
- 来源于 MAT 的表保留原 `pN` 编号，其余表依次取空闲编号；不写 `pN_title2`。
- 导出文件可直接再次导入。
- 单变量不能超过 MAT 5 的 2 GB 上限；按列以 64 KiB 缓冲分块流式写入，不额外分配整表数值矩阵。
- 仅在 `ENABLE_MAT=ON` 构建中可用。

## 导出前的时间基校验

XLSX 与 MAT 导出前都会校验同一来源表内所有信号的样本数和时间基。样本数不同、或偏移后的时间列逐样本不一致时拒绝导出，不会套用第一列时间，也不会覆盖已有文件。

## 同名文件与来源隔离

不同目录的同名文件独立管理，信号树用 `[2]` 等后缀区分；内部以规范化完整路径 + 表序号定位来源，不以显示名称合并导出。组内累计时间偏移不同的信号会导出到不同工作表/矩阵。
