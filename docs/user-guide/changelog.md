# 更新记录

## 未发布 · 2026-10-20

- 状态行管理和前后变化定位、航迹配置／视角／适应操作移入各类子图的右键菜单；主菜单和子菜单统一样式，隐藏项不再留下空白。
- 修复短状态脉冲跨越像素桶边界时随缩放漏显示的问题；压缩时保留紫色标记，放大后显示实际状态颜色。
- 新增“设置 → CLI 自动化…”入口，可在已打开的窗口中开启／关闭 CLI，复制连接路径和调用命令；构建时将 CLI 脚本放到 exe 同目录。

## 0.5.0 · 2026-10-19

- 新增二值／枚举状态时间图，支持行显隐和排序、前后变化定位、原始采样游标值及顶部图例；混排曲线保持 X 轴对齐，拖动时保留已有状态帧。
- 修复普通状态连接处误显示深色标记；密集变化仍保留提示。切换状态视图不再自动打开配置栏。
- 信号属性统一在右侧可调宽面板编辑，跟随信号选择，集中管理名称、时间偏移、样式及枚举；文件／分组偏移也在属性面板编辑。
- 右键统一通过“切换视图”选择曲线、航迹或状态图，移除图内返回曲线按钮。
- 航迹可直接进入空白视图，位置、坐标系及姿态来源通过飞机对象配置；航迹配置与对象航迹样式统一到右栏，共用颜色控件，名称、颜色、线宽和显隐随“应用”提交。
- 位提取、自定义公式和时间合并均支持一条规则多个输出；位提取默认自动字宽和小端，公式提供清晰的编辑区及示例。
- 时间合并的每个输出独立配置输入组，可在输出卡片直接选择、拖入、替换和移除信号；按时间排序、不插值，同时间同值去重，冲突仅影响对应输出。
- 输出编辑和复制保留身份、样式、枚举及内部依赖，删除受下游引用保护。处理列表改为规则卡片，集中显示状态、来源与参数，预览通过悬停查看，移除绘图勾选框。
- 左侧采用“信号／处理／对象”分栏；派生规则属于独立处理配置，直接引用原始信号或此前结果。对象字段来源可跳转到已绑定信号或未绑定分组。
- 丢包检测支持累计丢包数、累计丢包率、窗口丢包率三选一，默认窗口率；支持时间及显式 Y 计数语义、回绕与容差，自动识别保留已有规则和手动周期。
- 修复文件名命中搜索时子信号未过滤、来源变化后旧输入误绑定、后台退出保存提示不可见等问题；按文件稳定分配原始信号颜色。
- 优化处理配置摘要、来源索引和编辑候选查询；合并时间轴缓存与独立参考算法分别用于生产和回归。
- 格式要求：仅接受会话 v22、视图模板 v5；旧格式明确拒绝且保持原文件，不执行迁移。会话不保存计算数组，恢复后重新计算。

## 0.4.0 · 2026-10-16

- 修复移除数据文件后派生输出和子图图例残留：级联清理依赖该文件的规则及下游输出，保留独立分支和对象字段配置。
- 新增“丢包检测”对象类型及设置中的“自动识别”按钮，按原始时间轴分组创建检测，周期输入框预填估算值并支持修改；输出累计丢包数和累计丢包率。加载文件不创建对象，重复识别保留已有配置。会话升级 v13，继续读取 v1–v12。
- CLI 增加任务 ID、进度、真实成功/失败、取消及 requestId 重试；help 返回机器可读参数与结果 schema。
- 新增飞机原子批量配置、位置/姿态/单位与游标模型检查、别名映射模板预览和复用。
- 同源信号支持先预览冲突与已有规则再执行，重复执行复用结果；支持更新现有规则及取消后重算。
- 信号树增加逻辑结果视图，对象规则支持搜索、筛选及分页；CLI 可导出逻辑结果数据与来源清单。
- 同源合并复用共享时间线，减少重复排序和时间数组内存；保持原始值与冲突语义。

- 新增显式开启的本机 JSON CLI，支持 agent 加载/发现信号、读取原始样本、区间统计、设置布局/样式/偏移及保存恢复会话，见[自动化指南](automation-cli.md)。
- CLI 支持创建飞机对象、绑定位置/姿态字段、显示航迹、查询后台准备状态、切换视角及捕获窗口 PNG。
- CLI 支持清空工作区数据，以及按明确来源分组批量创建同源信号合并规则，保留冲突错误和原始来源。

## 0.3.0 · 2026-10-15

- 新增“按时间合并同源信号”派生规则，支持跨分组的 2–256 个输入，按实际时间戳与偏移合并，不插值；同时间同值去重，不同有效值报错。
- 合并结果支持绘图、导出及来源变化后自动重算。会话升级 v11，继续读取 v1–v10；旧版程序不能读取 v11。
- 修复添加或删除对象字段时乱序、滚动跳动：普通字段保持添加顺序，列表按稳定字段 ID 局部更新。
- 按职责整理源码目录及工程导航，清理已弃用文件。

## 0.2.0 · 2026-10-10

- 派生计算按规则依赖更新，保留独立分支的结果与错误；航迹模式暂停隐藏时间曲线 LOD。
- 视图模板升级为精简 v2，只保存被引用信号及绘图配置，继续读取旧 v1；旧版程序不能读取新模板。会话保持 v10。
- 合并航迹重复状态和信号引用更新，拆分信号浏览区、会话对话框及计算/模板职责。
- 修复密集曲线在缩放及选中加粗时的边缘凸点。

- 修正规则窗口重复的确定/取消按钮。飞机预置字段按配置启用时创建、始终置顶，类型往返保留名称、身份及绑定，避免重复参数；会话升级 v10。
- 航迹来源统一选择飞机对象。对象自动命名、双击重命名；信号树随当前对象同步全部绑定，支持直接拖到字段绑定。修正浅色/深色下拉选项的高亮文字。
- 修正对象/字段选中时的文字与来源显示；数值字段自动命名、双击重命名。飞机固定参数不可删除，配置支持 XYZ、欧拉角/四元数及航迹视图相同的姿态约定。

- 对象编辑直接切换右侧绘图区；从左侧信号树勾选或拖放绑定字段，支持常规/飞机类型及飞机固定预置参数，修正浅色和深色编辑配色。

- 新增对象统一管理；对象内绑定来源并创建状态字拆位、位段、换算、三轴模长和公式派生曲线，支持后台计算及 v10 会话恢复。

- 双击 T1/T2/ΔT 精确输入时间；支持原始样本吸附及视窗外定位。
- 航迹配置默认收起，按子图记住展开状态，保留紧凑管理栏和底部读数。
- 新增视图模板保存、信号匹配预览、应用与一次撤销，方便更换同结构数据后复用配置。

## 0.1.0 · 2026-10-09

首个正式版本，Windows x64 便携 ZIP；解压整个目录后运行 `DataInspector.exe`，包含 Qt 运行依赖及 MAT 支持。

### 2026-10-09

- 关于入口移至设置菜单；无修改构建保留时间与元数据，避免重复编译。
- 选择游标或缩放模式后立即启用该模式。

- 新增关于页面：版本、北京时间（UTC+8）构建时间、Git 提交/分支/工作区状态、Qt、架构和 MAT 支持；支持复制构建信息。
- 优化共用编译库、信号搜索和拖拽交互。
- 增加会话未保存提醒、来源文件重定位恢复和 PNG 图片导出。

### 2026-10-08

- 改善信号树分组标题、路径导航、展开折叠和滚动稳定性。
- 支持拖拽信号到指定子图，完善取消和重复添加行为。
- 改善游标示数拖动、双游标选择和子图激活。

### 已有功能

- Qt Quick Scene Graph 曲线绘制，后台加载和保峰值 LOD。
- CSV/TXT/XLSX/MAT 数据导入，XLSX/MAT 数据导出。
- 多子图、平移缩放、原始样本游标、信号样式和时间偏移。
- 二维/三维航迹、经纬度投影、多航迹与实际测量姿态显示。
- 版本化 JSON 会话保存与恢复。

本记录为用户功能摘要；同版本的具体源码以关于页面中的 Git hash 和工作区状态为准。正式版本使用 `v<版本号>` 标签。
