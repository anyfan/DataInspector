# 更新记录

## 开发中 · 2026-10-10

- 双击 T1/T2/ΔT 精确输入时间；支持原始样本吸附及视窗外定位。
- 航迹配置默认收起，按子图记住展开状态，保留紧凑管理栏和底部读数。
- 新增视图模板保存、信号匹配预览、应用与一次撤销，方便更换同结构数据后复用配置。

## 0.1.0 · 2026-10-09

首个正式版本，Windows x64 便携 ZIP；解压整个目录后运行 `DataInspector.exe`，包含 Qt 运行依赖及 MAT 支持。

### 2026-10-09

- 关于入口移至设置菜单；无修改构建保留时间与元数据，避免重复编译。
- 选择游标或缩放模式后立即启用该模式。

- 新增关于页面：版本、北京时间（UTC+8）构建时间、Git 提交/分支/工作区状态、Qt、架构和 MAT 支持；支持复制构建信息。
- 优化共用编译库、信号搜索和拖拽交互。
- 增加会话未保存提醒、来源文件重定位恢复和 PNG 图片导出。

### 2026-10-08

- 改善信号树分组标题、路径导航、展开折叠和滚动稳定性。
- 支持拖拽信号到指定子图，完善取消和重复添加行为。
- 改善游标示数拖动、双游标选择和子图激活。

### 已有功能

- Qt Quick Scene Graph 曲线绘制，后台加载和保峰值 LOD。
- CSV/TXT/XLSX/MAT 数据导入，XLSX/MAT 数据导出。
- 多子图、平移缩放、原始样本游标、信号样式和时间偏移。
- 二维/三维航迹、经纬度投影、多航迹与实际测量姿态显示。
- 版本化 JSON 会话保存与恢复。

本记录为用户功能摘要；同版本的具体源码以关于页面中的 Git hash 和工作区状态为准。发布标签为 `v0.1.0`。
