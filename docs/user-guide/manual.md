# 使用指南

> **状态**：现行 · **读者**：最终用户（不需要懂代码）· **相关功能页面**：[数据格式](data-formats.md)、[视图操作](view-operations.md)、[航迹](trajectory.md)、[信号树与样式](signals-and-styling.md)、[会话](session.md)

本指南面向**只需要用 DataInspector 看图、对比信号、导出数据**的用户。不需要了解任何代码、构建过程或文件位置。

---

## 1. 启动与加载数据

### 启动程序

双击 `DataInspector.exe` 即可。启动时会先出现一个带呼吸圆点和进度条的启动画面，主界面准备好后自动淡出。

### 加载数据文件

以下三种方式任选：

1. **点"打开"按钮**：在文件选择器里多选一个或多个 `.csv` / `.txt` / `.xlsx` / `.mat` 文件。
2. **拖进窗口**：把文件从资源管理器直接拖到 DataInspector 窗口里。
3. **拖到 exe 图标上**：把文件拖到 `DataInspector.exe` 图标上启动，程序打开后会自动加载这些文件；如果拖的是 `.disession` 会话文件，则直接恢复上次的工作区。

> 多选文件会在后台批量加载，窗口下方进度条显示总进度。加载期间可以继续操作其他已加载的图。

### 支持的数据文件

- **CSV / TXT**：第一行是表头，第一列是时间，其余列是信号。
- **XLSX**：每个工作表当作一张表，第一行表头、第一列时间。
- **MAT**：MATLAB Level 5 文件，识别 `p1`、`p2`… 这种二维矩阵。

> 数值里不要写千位分隔符（应写 `1234`，不要写 `1,234`）。空单元格或读不出来的数会显示为断线。

## 2. 界面认识

工具栏“设置”→“关于”可查看版本、构建时间、Git hash 等信息及更新记录，并复制构建信息用于问题反馈。详见[关于与构建信息](about.md)。

主窗口分三块：

```
┌──────────────┬──────────────────────────────────┐
│   左侧信号树  │        右侧子图绘图区              │
│  (可隐藏)     │   1×1 / 1×2 / 2×1 / 2×2 / 自定义 │
│              │                                  │
├──────────────┴──────────────────────────────────┤
│  顶部工具栏：打开、导出、布局、会话、设置、帮助   │
└────────────────────────────────────────────────┘
```

- **左侧信号树**：按"文件 → 数据表 → 信号"分层。每个信号前面有勾选框，后面跟着一段线型预览。
- **右侧子图区**：可以是一个大图，也可以切成多个子图。当前活动子图带蓝色边框。
- **顶部工具栏**：所有操作都在这里。

## 3. 画出第一条曲线

1. 加载完数据后，左侧信号树会列出所有文件和信号。
2. 点一下右侧你想画到哪个子图上（该子图出现蓝色边框）。
3. 在左侧信号树勾选信号前的方框。曲线立即画出来，并自动适配视图。
4. 想改这条线的样子？**单击信号行里那段彩色线型预览**，直接弹出线条属性对话框。

### 换布局

工具栏"布局"按钮提供：

- `1×1`、`1×2`、`2×1`、`2×2` 四种快捷网格
- 1–8 行 × 1–8 列的自定义网格

切换布局时，已经画在子图上的信号会尽量保留。

### 把信号挪到另一个子图

直接**拖动图顶部的图例**，拖到目标子图上松手即可。

### 从某个子图移除信号

- **图例上右键** → "从当前子图移除"。
- 或者在左侧信号树取消勾选。

> 取消勾选只是不画出来，数据还在内存里；下次勾选又能画。要彻底删掉文件，在信号树里**右键文件名 → 移除文件**。

## 4. 视图操作

### 平移与缩放

| 操作 | 效果 |
| --- | --- |
| 在图上**按住左键拖动** | 平移视图 |
| 在图上**滚轮** | 以鼠标位置为中心，X/Y 双轴缩放 |
| 鼠标悬停在 **X 轴刻度区** 滚轮 | 只缩放时间轴 |
| 鼠标悬停在 **Y 轴刻度区** 滚轮 | 只缩放对应 Y 轴，且以鼠标处数值为中心 |
| 在轴刻度区**按住拖动出矩形** | 框选放大到该范围 |

### 自适应

工具栏"自适应"菜单，或者用快捷键：

| 操作 | 快捷键 |
| --- | --- |
| 自适应当前视图 X/Y | `Ctrl+Alt+F` |
| 自适应全部视图 X/Y | `Ctrl+Alt+Shift+F` |
| 自适应当前时间轴 | `Ctrl+Alt+T` |
| 自适应全部时间轴 | `Ctrl+Alt+Shift+T` |
| 自适应当前 Y 轴 | `Ctrl+Alt+Y` |
| 自适应全部 Y 轴 | `Ctrl+Alt+Shift+Y` |
| 按空格（鼠标在图上） | 只适应当前子图的 Y 轴 |

> 所有子图共享同一个时间轴。"当前"只作用于你正在看的子图，"全部"作用于所有子图。把子图最大化后，自适应范围以这个大图为准。

### 撤销视图操作

按 `Ctrl+Z` 回退缩放、平移、框选、自适应、Y 轴归一化，最多回退 100 步。

> 在搜索框里打字时按 `Ctrl+Z` 是撤销文字，不会动视图。

### 全屏

按 `F11` 切换全屏。

## 5. 游标（读数）

### 开游标

工具栏点游标按钮：

- **单游标**：一条垂直虚线。
- **双游标**：两条垂直虚线，中间显示两者的时间差 ΔT。

开启时游标会自动落在当前时间范围的 25% 和 75% 处，并自动对齐到最近的真实数据点。
单游标切换到双游标保留 T1，将新 T2 放入当前视窗；视窗内没有原始样本时，T2 的时间位置仍在视窗内，信号读数仍查询最近原始样本。模式菜单始终保留一个选项勾选，关闭游标请点击工具栏主按钮。

### 读数

游标旁边会显示每个信号在该时刻的原始数值。两个游标之间显示 ΔT。
X 轴留白高度固定，游标时间读数紧贴轴线，红蓝边框对应两条游标，较粗边框表示当前键盘操作的游标。两条游标可见时差值始终显示，三个示数水平避让，窄视图省略过长数字；单游标或只有一条线可见时隐藏差值。读数只显示数字，悬停不显示文字或特殊鼠标图标。示数区域用于拖动游标，X 轴其他留白区域仍可框选。

### 拖动与键盘步进

双击轴下的 T1、T2 或 ΔT 可输入精确秒数，Enter 应用、Esc 取消；定位最近原始样本。编辑 ΔT 时固定 T1、调整 T2。详见[游标精确输入](view-operations.md#游标精确输入)。

- 直接**拖动游标**左右移动。两个游标拖过头会自动交换位置，不会穿过对方。
- 游标开启时，按键盘 **`←` / `→`** 让当前选中的游标跳到上一个/下一个真实数据点。点击或拖动另一条游标线切换操作目标；双游标独立移动，新开启的 T2 默认选中。
- 所有子图的游标位置是同步的。
- 点击 X 轴时间示数选中对应游标，拖动示数移动该游标；点击中间差值选中两个游标，拖动或按方向键整体移动并保持时间差，两条均在视窗内时到边界停止。

## 6. 信号样式与属性

**右键信号树里的某个信号**，可以：

- **重命名…**：改显示名。只影响图例和导出表头，不改源文件。
- **时间偏移…**：把整条信号沿时间轴平移。正数向右、负数向左。直接输入目标秒数，不累加。
- **线条属性…**：改颜色、线宽（1–20 px）、实线/虚线/点线/点划线。

**右键整个文件或数据表**："时间偏移…"会一次性作用于其下所有信号。

### 子图右键菜单

在绘图区右键：

- **自适应当前 Y 轴**
- **清除当前子图所有信号**
- **设置** → 里面可以开关：
  - **归一化 Y 轴**：把每条曲线按自己的最小值/最大值缩放到 0–1，方便对比量级差很多的信号。游标读数仍显示原始值。
  - **小幅值曲线置顶**：按信号平均幅值排序，小信号画在最上面不被大信号盖住。

## 7. 信号树小技巧

- **搜索**：信号树顶部有搜索框，输入关键词，命中的信号会加粗高亮。
- **吸顶表头**：信号很多往下滚的时候，顶部会 sticky 显示"当前在哪个文件、哪张表"，点一下跳回去，双击折叠。
- **隐藏信号树**：点搜索框右边的“‹”可以收起面板；想再打开，顶部菜单“设置 → 显示信号树”。面板顶部省去“信号 · 子图”和已加载文件摘要，搜索框下直接显示文件与信号列表。
- **同名文件**：加载了不同目录下同名的文件，第二个会显示为 `xxx [2]`，数据互不干扰。

## 8. 导出数据

点工具栏"导出数据"，可以选：

- **Excel · 全部已加载数据**
- **Excel · 当前所有子图已绘制的信号**
- **MAT · 全部已加载数据**
- **MAT · 当前所有子图已绘制的信号**
- **PNG · 当前子图 / 全部子图**：保存带坐标轴、图例和游标的图片，默认 2 倍分辨率，详见 [PNG 图片导出](image-export.md)。

说明：

- "全部已加载"会把内存里所有文件都导出。
- "当前所有子图已绘制"只导出你现在画在图上的那些信号，同一信号跨多个子图只导出一次。
- Excel 导出时，每个来源文件/数据表写成一个独立工作表；`NaN` 写成空单元格。
- 导出在后台跑，进度条是橙色的（导入是蓝色），旁边可以点取消。
- 导出的 MAT 文件可以再拖回来重新打开。

## 9. 保存工作现场（会话）

下次打开还想看到同样的布局、勾选的信号、游标位置？用会话。

### 保存

菜单"会话 → 保存会话…"（`Ctrl+S`），存成 `.disession` 文件。

保存内容包括：

- 你打开了哪些数据文件
- 子图布局、哪个子图最大化了
- 每个子图画了哪些信号
- 每条信号的名字、颜色、线宽、线型、时间偏移
- X 轴时间范围、各子图 Y 轴范围、归一化状态
- 游标模式和两个游标位置

### 恢复

菜单"会话 → 恢复会话…"（`Ctrl+Shift+O`），选之前存的 `.disession`。

> **会话不是数据备份**——它只记录"打开了哪些文件、怎么布置的"，不复制数据本身。搬移会话时，数据文件也要一起搬；最好把 `.disession` 和数据文件放在同一个相对目录里。

如果数据文件被删了、改了结构（表/列对不上），恢复会失败，当前打开的东西不会被破坏。

文件只是移动了位置时，可以在打开会话过程中逐个重新选择。成功恢复后重新保存会话来更新路径。标题末尾的 `*` 表示当前会话有未保存修改，关闭或替换时可以保存、放弃或取消。

## 10. 其他设置

经常用同一套配置分析不同数据时，可用“会话 → 保存为视图模板 / 应用视图模板”，在预览中核对信号匹配后复用布局、样式和航迹配置。默认坐标范围适应新数据，可选择固定范围；应用后可撤销一次。详见[视图模板](session.md#视图模板换数据复用配置)。

顶部菜单"设置"：

- **浅色/深色主题**：随时切换。
- **清除所有信号**：把所有子图上的曲线都去掉，但**不删已加载的数据**。下次勾选还能画。

## 11. 二维/三维航迹
在子图绘图区右键选择“切换为航迹视图”直接打开，默认经纬度。顶部可添加、删除和选择活动航迹；信号树新选信号依次填活动航迹空轴，已有轴不被覆盖，满轴后作为候选。每条航迹独立绑定坐标、名称、颜色、线宽和显隐，共用原点、范围、相机及一套 CAD 旋转环。经纬度输入为纬度（度）、经度（度）、记录高度（米），投影导航坐标 NED 为北/东/下；空间 XYZ 必须已使用相同 NED 坐标系。“样式 / 姿态”可绑定实际滚转/俯仰/航向或四元数并调整约定。启用共享时间游标后，每条航迹按原始位置及姿态样本显示简化飞机，缺失隐藏，读数说明时间差。左下环约束旋转，环内/中键/Alt 自由旋转，普通左键/Shift 平移，滚轮指针缩放；“时间图”保留原时间图绑定。底部悬停查看完整读数、公共原点和错误原因。

详见 [三维运动轨迹](trajectory.md)，包括数据要求、会话保存、缺失值和当前边界。

## 12. 常见问题

**Q：拖文件进窗口没反应？**
A：如果你是右键"以管理员身份运行"启动的程序，Windows 不允许资源管理器往高权限窗口拖文件。关掉程序，正常双击启动即可。

**Q：曲线中间断了一截？**
A：那一段数据是空的或读不出来（`NaN`），程序故意断线，不会瞎连。

**Q：Y 轴左边一大块空白？**
A：拖动一下窗口大小，或者按 `Ctrl+Alt+Y` 适应当前 Y 轴。

**Q：颜色用完了？**
A：程序固定用 14 个颜色，循环分配。想固定某条线的颜色，在信号属性里手动指定。

**Q：导出的 Excel 为什么分了好几个工作表？**
A：每个来源文件/数据表占一个工作表，方便对应。同表信号时间基不一致时会拒绝导出，避免时间对错。
