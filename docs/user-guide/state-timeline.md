# 状态时间轴

状态图将整数信号按时间显示为状态色带。数据提取、枚举含义与图面组织分别管理：处理页提取 bit／位段，信号属性定义枚举，状态图管理来源、顺序和显隐。

## 位提取

在“处理”中新建规则，类型选择“位提取（bit／位段）”。设置字宽（8／16／32）、起始 bit 和位数，bit0 为最低有效位。

在输出列表添加一条或多条输出，各自设置起始 bit、位数、名称和有符号解释；位数为 1 就是单 bit。多个独立 bit 使用多行、各填位数 1，无需切换模式。默认自动字宽、小端。

来源仅接受符合字宽的非负整数，非法或缺失样本输出缺失。提取结果可像其他派生信号一样画曲线、导出及继续处理，不改变原状态字。新建独立 bit 信号默认有“0 未生效／1 生效”枚举；其他位段不继承原状态字的枚举。

## 信号属性与枚举

从信号树进入“信号属性”，右侧可调宽面板内编辑名称、曲线样式和枚举表格，不弹出配置窗口；左侧信号树和中间图面保持可见，关闭面板后图面恢复宽度。原始和派生信号均可定义枚举。

每项填写整数、显示名称和颜色；点击颜色块在页内展开色板，也可填写颜色代码。重复值、空名称、非法整数或无效颜色不能应用。每个信号最多 256 项，整数范围为 ±(2^53−1)。

面板打开时，点击其他信号名称或勾选框会跟随切换，各信号草稿独立保留。名称／重命名、恢复原名称和时间偏移也在属性内编辑；原始信号可设置相对原始时间的绝对偏移，派生信号随输入时间变化。点击“应用”统一校验名称、样式、枚举和偏移，失败不部分提交；更新所有引用该信号的状态图；点击“还原”恢复已应用内容。返回信号树或切换信号时保留当前草稿，来源结构变化时关闭编辑并清除失效草稿。曲线图仍显示数值，枚举不改变计算和导出数值。

## 添加和管理状态行

1. 选择目标子图，通过图面右键菜单“切换视图 → 状态时间图”切换（不自动打开右栏），需要管理状态行时从右键菜单选择“属性…”打开右侧行管理。
2. 图面“属性…”在右侧面板打开行管理，支持显隐、上移、下移、移除以及跳转信号属性。
3. 点击“从信号树添加”，在树中点击名称或勾选来源完成添加；可取消并返回行管理。相同来源不会重复添加。

状态行只引用信号，不再各自定义 bit 提取或枚举。同一信号可以放入多个状态图，枚举共用；行顺序和显隐按子图独立保存。

每行 32 逻辑像素，左侧为彩色图标和活动游标数值，名称集中于顶部图例。点击图例选中并滚动到对应行；超出子图后使用右侧滚动条。状态图与曲线图保持网格等高、共享轴留白及 X 轴对齐，长名称不会撑宽左侧。

左侧读数查询最近原始样本、不插值，双游标跟随当前选中的 T1/T2。没有游标或有效整数样本时显示“—”，长数值悬停查看全文。状态图不绘制左侧连续数值 Y 轴。

“上次变化／下次变化”移动当前游标，必要时平移视窗；首次样本仅为记录基线。悬停显示状态含义、区间起点原始值和持续时间。时间区间采用前值保持，边沿仅表示首次观察到变化的采样时间。

未定义编码显示“未定义(数值)”，缺失或非整数显示灰色未知；普通状态边界仅按相邻状态颜色衔接，不额外绘制分隔线；紫色条纹表示一个像素内发生多次变化，或存在短于一个屏幕桶的完整状态区间（跨桶边界也保留标记），需要放大确认；进一步放大后显示实际状态颜色。纯平移／缩放保留已有画面并后台更新，首次无帧才显示准备提示。严格重复或乱序时间不支持状态区间；每子图最多 64 行、总计 200 万区间。

通过右键“切换视图”选择曲线视图、航迹视图或状态时间图；状态图右键菜单提供“属性…”和“上次变化／下次变化”，不显示曲线专用的 Y 轴操作和设置；图内不再显示这些按钮。

## 保存

当前会话 v22 在每个信号的 `enums` 保存定义；视图模板 v6 保存原始来源及派生输出的枚举，匹配或重建输出后应用，撤销模板时恢复；也包含相关对象和处理规则。状态行仅保存来源、名称和显隐，不保存区间缓存。会话仅接受 v22；模板写入 v6，允许读取迁移 v5，其中已有枚举保留。
