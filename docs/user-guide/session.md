# 会话保存与恢复

> **状态**：现行 · **读者**：最终用户 / AI 代理 · **关联代码**：`sessiondocument.*`、`appcontroller_session.cpp` · **改动会话格式必须同步本页**

## 使用入口

- **会话 → 保存会话…**（`Ctrl+S`）：保存为 `.disession`（也接受 `.json`）。
- **会话 → 恢复会话…**（`Ctrl+Shift+O`）：选择会话文件。已有数据时先确认。
- 内容是版本化 JSON，**不复制原始数据**。

## 保存内容

- 数据文件路径（优先相对会话文件所在目录）。
- 1–8 行/列布局、活动子图、最大化子图。
- 全部已加载信号的来源身份、原始名、显示名、颜色、线宽、线型、时间偏移。
- 各子图信号绑定、Y 范围、Y 归一化状态。
- 各子图的二维/三维模式、坐标类型、三个坐标来源、相机旋转角、缩放和平移。
- 共享 X 范围、游标模式和两个游标位置（包括视窗外的）。

应用主题、窗口大小、搜索过滤和树展开状态不写入会话。

## 身份与校验

- 会话格式 `format = "DataInspectorSession"`，`version = 6`（读取兼容 v1/v2/v3/v4/v5，v1 默认为时间序列视图，v2 航迹使用空间 XYZ）。
- 信号身份 = 文件索引 + 表序号 + 源列序号，同时保留表名和原始名作校验；显示名单独保存。
- 文件上限 10,000 条、信号上限 100,000 条、会话文件 16 MiB。
- 使用 `QSaveFile` 原子写入；校验或写入失败不替换旧文件。
- 结构与名称不变时，数据数值可以更新后再恢复；结构变化（表/列对不上）会拒绝恢复，当前会话保留。

## 恢复流程

1. 检查空闲状态；读取并校验 JSON。
2. 按保存顺序在后台加载所有文件（暂存，不替换当前会话）。
3. 全部加载成功后，逐表/逐列校验身份、原始名、时间偏移后的范围。
4. 校验全部通过，一次性切换数据仓库、模型、布局、绑定、样式。
5. 恢复 X/Y 范围和精确游标位置。

任何一步失败都丢弃暂存数据，保留当前会话。恢复期间禁用视图交互，控制器入口拒绝并行的加载/导出/保存。

## 边界

- 路径相对会话文件保存；会话与数据目录一起搬移后仍可恢复，跨盘等情况用绝对路径。
- 同名文件按独立来源定位，不依赖临时行号或显示名。
- 恢复支持尚未创建的子图；游标精确还原，不被当前视窗裁剪或重新吸附。
- **会话不是数据备份**。打开会话时，缺失或不可读的数据文件会逐个提示重新定位；取消选择保留当前会话。替代文件仍需通过原有表/列身份与名称校验，不进行部分恢复。成功重定位后请重新保存会话以更新路径。
- 数据来源、信号绑定/样式/偏移、布局、范围、游标和航迹配置/相机变化会标记未保存。关闭窗口或恢复另一会话时可保存、放弃或取消；保存失败或取消保存不会继续关闭/替换。搜索及树展开状态不触发提醒。没有自动保存。
- 事务式恢复需要同时保留旧数据和新加载数据，内存峰值可能更高。

## v2 轨迹字段

每个 `plots[]` 增加 `trajectory` 对象：`enabled` 为布尔值，`axes` 为三个信号索引（-1 表示未配置/来源已移除），`camera` 为 `[azimuth, elevation, zoom, panX, panY]`。

实际选择两个信号时自动显示二维航迹，选择三个时显示三维。空间 XYZ 允许留空任意一轴；经纬度绘图需要纬度和经度。来源不完整时保留配置并提示补选，允许保存空白航迹。保存格式仍为三元素 axes 数组，无需新增维数字段。

角度范围分别为 [-180,180] 和 [-90,90]，缩放 [0.05,100]，归一化屏幕平移各轴 [-1e6,1e6]（原 [-4,4] 限制已解除，支持高倍放大后的指针锚点和平移）。所有相机数值必须有限；超出数值保护范围时拒绝整个相机更新，不单独截断某轴。这一相机字段在 v6 中继续保留，列表扩展见下文。三维来源按原有文件/表/列身份恢复，保持 XYZ 顺序。v2 缺失或无效字段会拒绝读取，v1 使用默认轨迹状态。

## v3 经纬度模式

每个 `plots[].trajectory` 新增必填布尔值 `geographic`。`false` 表示空间 XYZ，`true` 表示输入顺序为纬度（度）、经度（度）、高度（米），显示为局部东/北/相对高度。原点由恢复后的首个有效非 `(0,0)` 定位重新计算，全部为零时回退首个有效样本，不复制投影数组。v3 缺失字段或类型错误会拒绝读取；v2 忽略该字段并使用空间 XYZ。

## v4 当前视图旋转

`plots[].trajectory` 新增必填 `rotation` 数组、`viewScale` 和 `panDepth`。`rotation` 为单位四元数 `[w,x,y,z]`，映射世界坐标至相机坐标；空数组表示沿用 `camera` 中的方位角和俯仰角。四元数分量必须有限，模长平方与 1 的差小于 1e-5。

`viewScale` 为投影比例除以画布短边及缩放倍数，范围 [0,1e6]，0 表示自动适应，旋转时固定为当前值。`panDepth` 为归一化相机深度平移，范围 [-1e6,1e6]；与 `camera` 的屏幕平移共同保存绕当前画面中心旋转后的状态。数值必须有限，缺字段或类型错误拒绝读取。

读取 v1–v3 使用旧角度和自动适应比例，深度平移为 0。当前版本保存始终写入 v6，旧版程序不能读取 v6 文件。

## v5 子图可用信号

`plots[].trajectory.signals` 是必填的信号索引数组，保存航迹子图的可用信号，顺序保留；可包含超过三个信号和未绑定信号。索引必须有效、不可重复，数量不超过 100,000；`axes` 中非 -1 的来源必须在该数组中。缺失、重复、越界或轴不属于可用列表时拒绝读取。

读取 v2–v4 时从已有 `axes` 的非 -1 来源去重建立可用列表，保留原轴映射。v1 默认为时间图。`plots[].signals` 继续保存原时间图绑定，与航迹可用列表分开恢复；删除文件时两者各自重映射。

## v6 多航迹与测量姿态

`plots[].trajectory.tracks` 为必填 1–64 项数组，`active` 为必填活动索引；保留子图共用 `enabled`、`signals` 和全部相机字段。兼容编辑入口的 `axes` / `geographic` 必须与 `tracks[active]` 完全一致，否则拒绝恢复。

每项包含 `id`（非空、最多 128 字符、子图内唯一）、`name`（非空、最多 256 字符）、布尔 `visible` / `geographic`、有效 `color`、有限 `width`（1–12）、三元素 `axes`（-1 或有效且不重复的信号索引）和必填 `attitude`。坐标、姿态来源均须属于共用 `signals`。有来源的航迹必须使用同一坐标类型；空配置允许保留，但不能以混合参考系进行叠加。

`attitude` 包含整数 `mode`（0 关闭、1 欧拉、2 四元数）、四元素 `sources`（-1 或信号索引），布尔 `radians`、`scalarLast`、`navigationToBody`，整数 `order`（0 Rz·Ry·Rx、1 Rx·Ry·Rz）。欧拉使用前三来源，四元数使用四来源。零姿态为 FRD→NED 单位变换。允许保存未绑定或被移除的姿态配置；运行时缺失模型隐藏并说明原因。

公共地理原点由列表中首条有效地理航迹的首个有效非零定位确定，全部零定位时回退首有效样本；隐藏不改变原点，删除或来源失效会重选。原点和派生投影缓存不写入 JSON；恢复使用当前原始数据重新计算，与已有会话允许数据数值更新的规则一致。

v1 转为空单航迹配置（时间图），v2–v5 的单航迹转换为列表第一项，姿态关闭、可见、线宽 2，颜色取原坐标时间源。v2 空间 XYZ，v3 起保留 geographic，v4 相机旋转，v5 候选来源均保留。严格结构校验和文件身份校验仍先完成，事务式恢复不进行部分切换。

## 视图模板：换数据复用配置

在“会话”菜单选择“保存为视图模板…”保存 `.diview`；加载新数据后选择“应用视图模板…”。模板复用布局、活动/最大化子图、信号显示名称/样式、绑定、归一化及航迹/姿态/相机配置，不加载模板来源文件、不复制原始数据、不替换当前会话路径。当前数据的时间偏移保留。

应用前显示匹配预览：优先按表名和原始信号名匹配；没有同表名候选时按表序号和原始名匹配（例如不同文件名的单表 CSV）。仅唯一候选自动匹配，缺失/重名需手动指定。同一目标信号不可分配给多个模板来源。只有配置引用的信号需要匹配，未引用的已加载信号保留。

默认 X/Y 范围适应新数据；勾选“使用模板中的固定坐标范围”沿用模板范围。保留当前游标模式并重新定位，不复用模板绝对游标时间。全部映射和结构校验通过后才应用；取消或验证失败保留当前视图。应用后“会话 → 撤销上次模板应用”可一次恢复此前配置；来源、样式或偏移变化导致 Store 代际改变后不再允许旧模板撤销。模板应用会标记会话未保存，保存模板本身不清除会话修改状态。

模板独立格式：顶层仅包含 `format = "DataInspectorViewTemplate"`、`version = 1`、`view`。`view` 使用现有严格版本化会话结构（当前 v6），来源路径仅作匹配说明，不参与加载。文件上限 16 MiB，使用 QSaveFile 原子保存；`.disession` 格式与兼容范围不变。
