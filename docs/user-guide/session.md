# 会话保存与恢复

> **状态**：现行 · **读者**：最终用户 / AI 代理 · **关联代码**：`sessiondocument.*`、`appcontroller_session.cpp` · **改动会话格式必须同步本页**

## 使用入口

- **会话 → 保存会话…**（`Ctrl+S`）：保存为 `.disession`（也接受 `.json`）。
- **会话 → 恢复会话…**（`Ctrl+Shift+O`）：选择会话文件。已有数据时先确认。
- 内容是版本化 JSON，**不复制原始数据**。

## 保存内容

- 数据文件路径（优先相对会话文件所在目录）。
- 1–8 行/列布局、活动子图、最大化子图。
- 全部已加载信号的来源身份、原始名、显示名、颜色、线宽、线型、时间偏移。
- 各子图信号绑定、Y 范围、Y 归一化状态。
- 共享 X 范围、游标模式和两个游标位置（包括视窗外的）。

应用主题、窗口大小、搜索过滤和树展开状态不写入会话。

## 身份与校验

- 会话格式 `format = "DataInspectorSession"`，`version = 1`。
- 信号身份 = 文件索引 + 表序号 + 源列序号，同时保留表名和原始名作校验；显示名单独保存。
- 文件上限 10,000 条、信号上限 100,000 条、会话文件 16 MiB。
- 使用 `QSaveFile` 原子写入；校验或写入失败不替换旧文件。
- 结构与名称不变时，数据数值可以更新后再恢复；结构变化（表/列对不上）会拒绝恢复，当前会话保留。

## 恢复流程

1. 检查空闲状态；读取并校验 JSON。
2. 按保存顺序在后台加载所有文件（暂存，不替换当前会话）。
3. 全部加载成功后，逐表/逐列校验身份、原始名、时间偏移后的范围。
4. 校验全部通过，一次性切换数据仓库、模型、布局、绑定、样式。
5. 恢复 X/Y 范围和精确游标位置。

任何一步失败都丢弃暂存数据，保留当前会话。恢复期间禁用视图交互，控制器入口拒绝并行的加载/导出/保存。

## 边界

- 路径相对会话文件保存；会话与数据目录一起搬移后仍可恢复，跨盘等情况用绝对路径。
- 同名文件按独立来源定位，不依赖临时行号或显示名。
- 恢复支持尚未创建的子图；游标精确还原，不被当前视窗裁剪或重新吸附。
- **会话不是数据备份**。不提供缺失文件重新定位向导、部分恢复、自动保存、未保存提示。
- 事务式恢复需要同时保留旧数据和新加载数据，内存峰值可能更高。
