# 对象与派生数据

从信号树上方点击“对象与派生数据…”，右侧绘图区切换为对象编辑页面，左侧信号树保持可用。点击“返回曲线”恢复原来的子图和视图。原始信号仍可独立绘图；所有派生规则及结果必须属于对象。

## 创建与绑定

1. 点击“新建对象”立即生成“对象 1”“对象 2”等名称；双击对象列表中的名称可重命名。在名称旁切换“常规”“飞机”或“丢包检测”类型。常规对象只包含数值字段。新飞机对象只创建经纬高，姿态默认关闭；切换 XYZ、开启欧拉角或四元数时才创建对应参数。已创建的字段保留名称与绑定，重新启用复用同一字段，预置参数始终排在普通数值字段前面。
2. 在“数据字段”中单击字段，再从左侧信号树勾选来源，或直接把原始信号拖到目标字段（无需预先单击）。拖动时目标字段高亮。树中勾选表示当前对象的全部来源，切换对象立即更新；取消勾选清除该对象中使用该来源的字段绑定，其他对象保留；拖入同一来源保持绑定。字段不再提供用途或来源下拉列表。常规对象尚未选中字段时，可直接勾选信号新建字段。
3. 点击“添加数值字段”直接生成“字段 1”“字段 2”等名称，无需输入；双击字段名称可重命名。数值字段可以绑定状态字、三轴分量或任何其他数值信号。字段允许引用不同文件；未选择来源时显示“未绑定”。
4. “复制配置”生成独立对象，初始复用相同来源与规则；编辑副本字段即可重新绑定数据。

飞机对象的“显示飞机航迹”使用纬度、经度和可选高度；完整的滚转/俯仰/航向用于飞机姿态。飞机配置与航迹视图一致：位置支持经纬高（度/米）或 XYZ（NED，米）；姿态可关闭、使用欧拉角或四元数，支持度/弧度、两种欧拉旋转顺序、wxyz/xyzw 和机体→导航/导航→机体方向。飞机预置参数不可删除、不可修改用途，可以解绑或双击改显示名称；额外数值字段可删除。不自动识别单位或坐标系。关联航迹随字段和对象名称更新，多个子图可引用同一对象；位置与测量姿态统一在对象中配置。相机和样式仍在航迹视图中管理。

可在对象名称旁切换类型，切换保留已有字段和规则；切换到飞机只补齐当前启用配置所需的参数；切换为常规后所有字段作为数值使用，并保留预置身份、名称、来源和规则，切回飞机不会重复创建。已有航迹关联的飞机须先移除所有引用它的航迹，再改为常规或丢包检测对象。浅色和深色模式下，编辑页面、对话框和下拉选项使用统一文字和背景配色。

## 派生规则

在对象“派生数据”中点击“新增派生规则…”。输入只能选择本对象字段或此前已建立的派生结果，不允许跨对象引用或循环依赖。

| 规则 | 配置与结果 |
| --- | --- |
| 状态字拆位 | 8/16/32 位字宽、起始 bit、位数；一次生成多条 0/1 曲线 |
| 提取位段 | 提取所选位数；可按二补码有符号解释 |
| 比例与偏置 | `x * 比例 + 偏置` |
| 三轴模长 | 明确选择 x/y/z，计算三轴模长 |
| 自定义公式 | 最多三个输入 x/y/z，生成新曲线 |

bit0 为最低有效位。例如 u8 数值 5 的 bit0、bit2 为 1，其余为 0。u8 拆全部位时，选择字宽 8、起始 bit 0、位数 8。默认结果名为“规则名.bit0”至“规则名.bit7”，可分别改名。

状态字仅接受有限、整数且在所选无符号字宽范围内的值，小数、负数、越界和缺失值留空并显示无效样本数量，不截断或取模。已有数值列拆位不涉及字节序；不解码多字节报文载荷，也不支持完整 u64。

公式支持 `+ - * /`、括号、比较 `> >= < <= == !=`、逻辑 `&& || !`，以及 `abs`、`sqrt`、双参数 `min/max`。例如 `sqrt(x*x+y*y+z*z)`、`x-y`、`x>=80 && y==1`。逻辑结果为 0/1；除零、非法开方、溢出和缺失输入产生缺失值。公式不执行脚本。

已建立规则可点击“编辑…”修改输入、公式和参数；保留输出身份、名称与样式。改变输出数量时新建规则，避免使下游引用悄然改变含义。非法配置留在编辑窗口中说明原因。

## 显示、追溯与保存

规则列表显示输入、算子、参数/公式、错误和每条输出前八个样本的预览。勾选输出在当前子图绘制；派生信号也位于信号树“对象 / 名称与身份 / 派生数据”，支持现有拖拽、图例、游标、样式和导出。右键派生信号打开对象管理。

当前子图为航迹时，管理窗口先提示切换为时间图，再允许勾选派生曲线，避免将位信号误填入航迹轴。切换保留对象航迹绑定，可随后返回航迹视图；也可关闭管理窗口，选择另一个时间子图再绘图。

拆位与位段使用阶梯线，缩小时保留每桶首尾与极值，便于看见短脉冲；细节应放大确认。游标访问计算生成的完整样本，保留实际样本时间，不查询 LOD 或插值值。

对象和规则随当前 v13 会话保存（读取兼容旧版本）；不保存计算数组，恢复后根据原始文件重新计算。显示名称和样式保留。复制对象用于运行内配置复用；现有视图模板只映射绘图配置，不自动创建缺失对象。

## 更新与删除

更换字段或改变原始时间偏移后，受影响规则的旧结果先清空，再后台重新计算；未受影响分支继续保留。手动将字段设为未绑定时保留规则并提示错误，重新绑定即可恢复。颜色、线宽和显示名称调整不触发数据计算。

显式移除原始数据文件时，程序会同时删除依赖该文件字段的派生规则及全部下游规则，并从信号树、所有子图图例/绘图绑定、航迹来源和导出集合中移除对应输出，不保留无来源的空曲线。多输入规则（包括合并规则）只要有一个输入来自被移除文件，就随其下游一起删除；不依赖该文件的独立规则保留原身份和配置。对象本身和字段名称保留，被删除文件的字段变为“未绑定”，可重新绑定并新建规则；丢包检测对象也可再次“自动识别”。

有规则引用的字段不能直接删除，可改为“未绑定”；有下游引用的规则须先删除下游。删除对象前确认，删除其所有规则、结果和绘图引用，关联航迹解除绑定；原始文件和信号保留。取消绘图勾选只影响当前视图。

## 当前边界

单源继承原始时间；多输入须逐样本时间完全相同（包括偏移），不插值或重采样。输入可乱序，多输入仍按原始次序校验。计算和索引构建在后台；计算未完成时不能导出数据或图片。

最多 256 个对象，每对象最多 256 个字段和 256 条规则，单规则最多三个输入、32 个输出。输出值数组预算 512 MiB（局部重算时包含所有未重算规则保留的结果），时间、索引和几何另计，超预算规则保留定义并显示错误。时间数组共享，但不代表任意规模都能装入内存。

本版未提供滤波、微积分、时间对齐、物理坐标变换、枚举/0/1 文本标签和对象模板文件导入。姿态显示约定通过飞机对象配置调整。

计算按规则依赖更新：字段来源或规则参数变化只重算受影响规则及其下游，独立分支保留结果和错误。修改对象、规则或输出显示名称及画笔不重算数值；时间偏移变化参与失效判断。连续编辑会取消旧任务，尚未提交的分支合并到下一次计算。

## 合并分散在不同分组的同源信号

在对象管理中创建常规对象，添加数值字段，并把各分组的同源信号分别绑定到字段。新增派生规则，选择“按时间合并同源信号”，勾选需要合并的字段（2–256 个），为输出命名后确定。输出可像其他派生信号一样绘图和导出，也可作为后续规则输入。

合并按包含时间偏移的实际时间戳升序排列，不插值、不生成新采样点，也不强制等间隔。交错采样可形成更密的信号；相同时间且相同值去重，缺失值与有效值重合时保留有效值，同一时间的不同有效值则报错并清空输出。非法时间戳和缺少来源也会报错。请自行确认输入属于同一物理量、单位和时间基准。原始来源保持不变，来源或偏移修改后自动重算。

对象面板的规则区支持按名称/来源/错误搜索、按成功/失败/计算中筛选，每页 20 条，并显示结果摘要。带诊断但有有效值的结果归为成功并标注警告，完整错误仍可查看。

信号树勾选“优先显示合并结果”后，成功合并的输入从树中隐藏，保留合并输出和独立信号；关闭即可回到全部来源。失败合并不隐藏原始输入。这是可逆显示选项，不改变工作区编号或已有绘图引用。CLI 可预览批量合并、复用飞机映射模板及导出带来源清单的逻辑结果包，见[自动化指南](automation-cli.md)。

## 丢包检测

加载文件只导入原始数据。需要检测时，点击“新建对象”，在对象类型中选择“丢包检测”，再点击对象设置中的“自动识别”。识别扫描当前已加载的全部原始文件，为各文件的不同完整采样时间轴建立检测：同时间轴的多列信号、不同表中逐点完全相同的时间轴共用检测，只绑定一个代表信号；相同周期但起点、缺口或时间偏移不同的时间轴分别检测，不跨文件合并。也可以手动绑定字段、新建丢包检测规则。

“采样周期（秒）”直接填入估算的数值，可直接修改，没有自动估算勾选框。新建规则或切换输入时预填该输入的估算周期，无法估算时留空提示手动填写。周期必须为有限正数；修改后重算两个输出及其下游，保留输出身份、样式和绘图绑定。重复点击自动识别仅补充当前对象中尚无检测的组，保留已有规则、名称、输出身份和手动周期；同时间组已绑定其他原始列时也不会重复添加。导入更多文件后，可再次点击补充检测。

规则生成两条阶梯曲线：`名称.累计丢包数` 和 `名称.丢包率(%)`。只读取原始采样时间，与输入信号值是否缺失无关。对相邻时间差 Δt、采样周期 T，新增丢包数为 `max(floor(Δt/T + 0.5) - 1, 0)`；每点丢包率为 `100 × 累计丢包数 / (累计丢包数 + 已收到点数)`。首点两项均为零，首点计作已收到的一个点，不推断记录首尾之外的丢包。例如时间为 0、1、2、5、6、7 秒，周期为 1 秒，累计丢包数依次为 0、0、0、2、2、2，末点丢包率为 25%。

自动周期使用最多 8192 个均匀抽取的相邻有限正时间差的中位数（偶数取上中位数），适用于多数采样间隔正常的固定频率数据。大面积丢包、变频采样或只有两个点时无法可靠识别真实周期，请按采集配置手动核定；抖动按最近整数周期折算，达到 1.5 倍周期开始计丢包。成功估算的周期按实际数值保存到会话；已有规则和人工修改不会在继续导入或会话恢复时重置。底层仍支持旧规则的 0 值，首次成功计算后转为实际周期。

全部时间戳必须有限且严格递增；重复、倒退、无效时间、无法自动估算及计数超出双精度精确整数范围均报错并清空两个输出。不会排序、去重或补造样本。单点需手动指定周期后输出零；初始估算需要至少一个可用间隔。结果可像其他派生信号一样绘图、游标查询、引用和导出。

识别在后台读取不可变原始快照，不阻塞界面逐点扫描，不自动勾选输出。每对象最多 256 个字段和规则；超过上限时整批不提交并提示，可手动选择所需输入并分配到多个检测对象。识别期间数据变化会拒绝过期结果；清空或取消计算不会稍后提交已取消的识别。单点或非法时间轴保留检测规则并报告错误，可手动指定周期后修复。

对象类型、规则和已修改周期随 v13 会话保存，恢复只还原已有定义，不触发自动识别。先前版本创建的常规对象与规则保留，可把对象切换为“丢包检测”后使用按钮；不会自动删除或转换既有对象。移除原文件会级联清理依赖它的检测规则及下游输出，保留对象和未绑定字段；重新导入后可再次“自动识别”建立检测。
