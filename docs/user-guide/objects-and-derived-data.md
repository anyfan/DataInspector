# 对象与派生数据

左侧“信号”栏显示原始信号，“处理”栏显示派生信号及独立处理配置入口，“对象”栏管理对象字段和飞机配置。对象栏点击“新建对象”直接创建飞机对象；点击名称进入字段编辑，可搜索或右键重命名、复制和删除对象。飞机行的勾选框显示/隐藏其在当前子图的航迹，右侧短线显示航迹样式，点击可配置颜色和线宽；处理栏点击“管理处理规则…”进入规则编辑页面，点击“返回曲线”恢复子图。处理规则不再属于对象；无需创建对象即可计算派生信号。

## 创建与绑定

1. 对象栏“新建对象”生成“飞机 1”“飞机 2”等名称；对象栏和编辑页的新建入口均默认飞机类型，需要常规对象时可在类型下拉框切换；双击对象列表中的名称可重命名。在名称旁切换“常规”或“飞机”类型。常规对象只包含数值字段。新飞机对象只创建经纬高，姿态默认关闭；切换 XYZ、开启欧拉角或四元数时才创建对应参数。已创建的字段保留名称与绑定，重新启用复用同一字段，预置参数始终排在普通数值字段前面。
2. 在对象页面单击字段，单击字段的“未绑定”或点击“选择来源…”切回信号栏，再从左侧信号树勾选来源，或直接把原始信号拖到目标字段（无需预先单击）。拖动时目标字段高亮。树中勾选表示当前对象的全部来源，切换对象立即更新；取消勾选清除该对象中使用该来源的字段绑定，其他对象保留；拖入同一来源保持绑定。字段不再提供用途或来源下拉列表。常规对象尚未选中字段时，可直接勾选信号新建字段。
3. 点击“添加数值字段”直接生成“字段 1”“字段 2”等名称，无需输入；双击字段名称可重命名。数值字段可以绑定状态字、三轴分量或任何其他数值信号。字段允许引用不同文件；未选择来源时显示“未绑定”。单击“未绑定”会选中该字段并切到原始信号栏；单击已绑定来源会清除搜索、展开分组并定位到对应信号，信号栏已隐藏时会自动显示。导航保持对象编辑页打开，不改变绑定。
4. “复制配置”生成独立对象，初始复用相同字段来源；不复制或改变独立处理规则。编辑副本字段即可重新绑定数据。

飞机对象的“显示飞机航迹”使用纬度、经度和可选高度；完整的滚转/俯仰/航向用于飞机姿态。飞机配置与航迹视图一致：位置支持经纬高（度/米）或 XYZ（NED，米）；姿态可关闭、使用欧拉角或四元数，支持度/弧度、两种欧拉旋转顺序、wxyz/xyzw 和机体→导航/导航→机体方向。飞机预置参数不可删除、不可修改用途，可以解绑或双击改显示名称；额外数值字段可删除。不自动识别单位或坐标系。关联航迹随字段和对象名称更新，多个子图可引用同一对象；位置与测量姿态统一在对象中配置。航迹样式可从对象行右侧短线或航迹视图“样式”配置；相机在航迹视图中管理。同一飞机在不同子图的航迹样式独立，切换、隐藏及重新显示保留已有颜色与线宽。

可在对象名称旁切换类型，切换保留已有字段；切换到飞机只补齐当前启用配置所需的参数；切换为常规后所有字段作为数值使用，并保留预置身份、名称和来源，切回飞机不会重复创建。已有航迹关联的飞机须先移除所有引用它的航迹，再改为常规对象。浅色和深色模式下，编辑页面、对话框和下拉选项使用统一文字和背景配色。

## 派生规则

切换到“处理”栏，点击“管理处理规则…”→“新建处理配置”，然后点击“新增派生规则…”。输入直接选择已加载的原始信号，或本处理配置此前建立的派生结果；不依赖对象字段，不允许跨配置或循环依赖。处理配置可重命名、复制和单独删除，不再区分“通用处理”和“丢包检测”类型；丢包检测与其他操作一样，在派生规则的操作列表中选择。

新增时自动填入当前配置未占用的“规则1”“规则2”等名称，可直接修改。切换规则类型保留已输入的名称；取消不占用编号，编辑已有规则保留原名。此时只建立编辑草稿，点击“应用”后才创建输出。

新增和编辑规则在右侧页面内展开，不弹出模态窗口。输入统一显示为独立槽位，标明变量名和必填/可选状态：拆位、位段、比例偏置、丢包检测只显示 X；三轴模长显示必填的 X/Y/Z；公式显示 X 及可选的 Y/Z。新建规则时 X/Y/Z 均为空，不自动绑定首个信号。点击变量名、来源名称或“从信号树选择”仅激活对应输入，保留左侧当前栏目、搜索、展开与滚动位置，在左侧点击信号名称或勾选即可替换该输入，树中勾选表示当前激活输入，不改变曲线显示。也可将信号直接拖入任意槽位，无需先选中，拖动时目标高亮，松开绑定；无效来源显示红色边框并拒绝绑定，Esc 取消拖拽。“解除”仅清空对应槽位。公式输入按 X/Y/Z 连续绑定，使用 Z 时需同时绑定 Y，缺项时应用会提示，不会把 Z 当成 Y。

合并规则显示编号输入列表。从左侧勾选信号或拖入“添加输入”区追加，拖到已有输入可替换；“移除”或取消树中勾选可删除。重复拖入同一信号不重复添加，替换成列表中已有来源会提示；至少两个不同输入才能应用。切到“处理”栏可选择本配置中此规则之前的结果；所有输入均拒绝其他配置、当前规则及其后续结果。

X/Y/Z 输入槽整块区域都可单击激活，包括文字外的留白和边缘，无需反复点击文字。“解除”“移除”等按钮仍分别执行各自操作。

修改名称、输入和参数后，点击“应用”才更新规则并计算；“取消”放弃此次编辑。通过“返回曲线”暂时离开后，再进入同一处理配置会保留未应用的草稿；切换处理配置或重新打开另一规则会结束此前编辑。编辑期间加载或移除来源后须重新打开规则，避免引用已变更的信号。

| 规则 | 配置与结果 |
| --- | --- |
| 状态字拆位 | 8/16/32 位字宽、起始 bit、位数；一次生成多条 0/1 曲线 |
| 提取位段 | 提取所选位数；可按二补码有符号解释 |
| 比例与偏置 | `x * 比例 + 偏置` |
| 三轴模长 | 明确选择 x/y/z，计算三轴模长 |
| 自定义公式 | 最多三个输入 x/y/z，生成新曲线 |

bit0 为最低有效位。例如 u8 数值 5 的 bit0、bit2 为 1，其余为 0。u8 拆全部位时，选择字宽 8、起始 bit 0、位数 8。默认结果名为“规则名.bit0”至“规则名.bit7”，可分别改名。

状态字仅接受有限、整数且在所选无符号字宽范围内的值，小数、负数、越界和缺失值留空并显示无效样本数量，不截断或取模。已有数值列拆位不涉及字节序；不解码多字节报文载荷，也不支持完整 u64。

公式支持 `+ - * /`、括号、比较 `> >= < <= == !=`、逻辑 `&& || !`，以及 `abs`、`sqrt`、双参数 `min/max`。例如 `sqrt(x*x+y*y+z*z)`、`x-y`、`x>=80 && y==1`。逻辑结果为 0/1；除零、非法开方、溢出和缺失输入产生缺失值。公式不执行脚本。

已建立规则可点击“编辑…”修改输入、公式和参数；保留输出身份、名称与样式。改变输出数量时新建规则，避免使下游引用悄然改变含义。非法配置留在编辑窗口中说明原因。

编辑时也可切换到此前未使用的原始信号。规则窗口打开期间若数据来源发生变化，需要重新打开规则并确认输入，避免来源行号变化后误绑定。

## 显示、追溯与保存

规则列表显示输入、算子、参数/公式、错误和每条输出前八个样本的预览。勾选输出在当前子图绘制；派生信号只显示在“处理”栏的“处理 / 配置名称与身份”分组中，支持现有拖拽、图例、游标、样式和导出。右键派生信号打开所属处理配置。

当前子图为航迹时，管理窗口先提示切换为时间图，再允许勾选派生曲线，避免将位信号误填入航迹轴。切换保留对象航迹绑定，可随后返回航迹视图；也可关闭管理窗口，选择另一个时间子图再绘图。

拆位与位段使用阶梯线，缩小时保留每桶首尾与极值，便于看见短脉冲；细节应放大确认。游标访问计算生成的完整样本，保留实际样本时间，不查询 LOD 或插值值。

对象与独立处理配置随当前 v15 会话分别保存（读取兼容 v1–v14）；旧对象中的规则自动迁移为独立处理配置，复制原始来源映射，保留规则、输出身份及样式。不保存计算数组，恢复后根据原始文件重新计算。显示名称和样式保留。复制对象或处理配置用于各自的运行内配置复用；现有视图模板只映射绘图配置，不自动创建缺失对象。

## 更新与删除

修改处理规则输入或改变原始时间偏移后，受影响规则的旧结果先清空，再后台重新计算；未受影响分支继续保留。对象字段的解绑或重绑不再影响处理结果。颜色、线宽和显示名称调整不触发数据计算。

显式移除原始数据文件时，程序会同时删除依赖该文件来源的派生规则及全部下游规则，并从信号树、所有子图图例/绘图绑定、航迹来源和导出集合中移除对应输出，不保留无来源的空曲线。多输入规则（包括合并规则）只要有一个输入来自被移除文件，就随其下游一起删除；不依赖该文件的独立规则保留原身份和配置。对象、处理配置本身与名称保留，已删除来源映射为“未绑定”，可重新选择输入并新建规则；丢包检测配置也可再次“自动识别”。

有下游引用的规则须先删除下游。删除对象只解除对象及其航迹关联，独立处理配置、结果和绘图保留；删除处理配置会删除该配置的规则、结果和绘图引用。两者均需确认，原始文件和信号保留。取消绘图勾选只影响当前视图。

## 当前边界

单源继承原始时间；多输入须逐样本时间完全相同（包括偏移），不插值或重采样。输入可乱序，多输入仍按原始次序校验。计算和索引构建在后台；计算未完成时不能导出数据或图片。

对象与处理配置各最多 256 个；每对象最多 256 个字段，每处理配置最多 256 个来源映射和 256 条规则，单规则最多三个输入、32 个输出。输出值数组预算 512 MiB（局部重算时包含所有未重算规则保留的结果），时间、索引和几何另计，超预算规则保留定义并显示错误。时间数组共享，但不代表任意规模都能装入内存。

本版未提供滤波、微积分、时间对齐、物理坐标变换、枚举/0/1 文本标签和对象模板文件导入。姿态显示约定通过飞机对象配置调整。

计算按规则依赖更新：处理输入来源或规则参数变化只重算受影响规则及其下游，独立分支保留结果和错误。修改对象、规则或输出显示名称及画笔不重算数值；时间偏移变化参与失效判断。连续编辑会取消旧任务，尚未提交的分支合并到下一次计算。

## 合并分散在不同分组的同源信号

在“处理”栏新建通用处理配置，新增派生规则，选择“按时间合并同源信号”，直接勾选需要合并的原始信号（2–256 个），为输出命名后确定。输出可像其他派生信号一样绘图和导出，也可作为后续规则输入。

合并按包含时间偏移的实际时间戳升序排列，不插值、不生成新采样点，也不强制等间隔。交错采样可形成更密的信号；相同时间且相同值去重，缺失值与有效值重合时保留有效值，同一时间的不同有效值则报错并清空输出。非法时间戳和缺少来源也会报错。请自行确认输入属于同一物理量、单位和时间基准。原始来源保持不变，来源或偏移修改后自动重算。

处理页面的规则区支持按名称/来源/错误搜索、按成功/失败/计算中筛选，每页 20 条，并显示结果摘要。带诊断但有有效值的结果归为成功并标注警告，完整错误仍可查看。

“处理”栏的“隐藏失败的合并结果”可隐藏失败合并输出；“信号”栏始终保留原始信号。CLI 仍可查询完整的逻辑结果集合及导出带来源清单的结果包，见[自动化指南](automation-cli.md)。

## 丢包检测

加载文件只导入原始数据。需要检测时，进入“处理”栏，新建或选择处理配置，点击“新增派生规则…”，在操作列表选择“丢包检测”，再点击“自动识别”。识别启动后返回规则列表，结果直接加入当前处理配置；无需为批量识别填写规则名称。识别扫描当前已加载的全部原始文件，为各文件的不同完整采样时间轴建立检测：同时间轴的多列信号、不同表中逐点完全相同的时间轴共用检测，只绑定一个代表信号；相同周期但起点、缺口或时间偏移不同的时间轴分别检测，不跨文件合并。也可以新增丢包检测规则并从信号树选择原始输入。

“采样周期（秒）”直接填入估算的数值，可直接修改，没有自动估算勾选框。新建规则或切换输入时预填该输入的估算周期，无法估算时留空提示手动填写。周期必须为有限正数；修改后重算所选输出及其下游，保留输出身份、样式和绘图绑定。重复点击自动识别仅补充当前处理配置中尚无检测的组，保留已有规则、名称、输出身份和手动周期；同时间组已绑定其他原始列时也不会重复添加。导入更多文件后，可再次点击补充检测。

新增规则从“累计丢包数”“累计丢包率(%)”“窗口丢包率(%)”三项中选择，只生成所选的一条阶梯曲线，默认窗口丢包率。X 采样时间模式只读取原始采样时间，与输入信号值是否缺失无关。对相邻时间差 Δt、采样周期 T，新增丢包数为 `max(floor(Δt/T + 0.5) - 1, 0)`；累计模式下每点丢包率为 `100 × 累计丢包数 / (累计丢包数 + 已收到点数)`。首点所选指标均为零，首点计作已收到的一个点，不推断记录首尾之外的丢包。例如时间为 0、1、2、5、6、7 秒，周期为 1 秒，累计丢包数依次为 0、0、0、2、2、2，末点丢包率为 25%。

自动周期使用最多 8192 个均匀抽取的相邻有限正时间差的中位数（偶数取上中位数），适用于多数采样间隔正常的固定频率数据。大面积丢包、变频采样或只有两个点时无法可靠识别真实周期，请按采集配置手动核定；抖动按最近整数周期折算，达到 1.5 倍周期开始计丢包。成功估算的周期按实际数值保存到会话；已有规则和人工修改不会在继续导入或会话恢复时重置。底层仍支持旧规则的 0 值，首次成功计算后转为实际周期。

全部时间戳必须有限且严格递增；重复、倒退、无效时间、无法自动估算及计数超出双精度精确整数范围均报错并清空所选输出。不会排序、去重或补造样本。单点需手动指定周期后输出零；初始估算需要至少一个可用间隔。结果可像其他派生信号一样绘图、游标查询、引用和导出。

识别在后台读取不可变原始快照，不阻塞界面逐点扫描，不自动勾选输出。每对象最多 256 个字段和规则；超过上限时整批不提交并提示，可手动选择所需输入并分配到多个检测对象。识别期间数据变化会拒绝过期结果；清空或取消计算不会稍后提交已取消的识别。单点或非法时间轴保留检测规则并报告错误，可手动指定周期后修复。

处理配置、规则和已修改周期随 v15 会话保存，恢复只还原已有定义，不触发自动识别。旧会话中的丢包检测配置与规则继续可用，界面统一按处理配置编辑；旧对象规则按会话迁移逻辑拆分到独立处理配置，无需切换类型。移除原文件会级联清理依赖它的检测规则及下游输出，保留对象和未绑定字段；重新导入后可再次“自动识别”建立检测。

### Y 递增计数检测

新建或编辑“丢包检测”规则，选择检测依据。X 采样时间保持原周期算法；Y 模式使用选中信号的原始数值，结果仍沿原始 X 时间轴显示。

| 模式 | 输入含义与参数 | 新增丢包 |
| --- | --- | --- |
| Y 计数：逐帧 | 完整记录的发送帧序号；每帧计数步长 S，默认 1 | 正向计数增量 / S − 1 |
| Y 计数：固定间隔抽样 | 每次正常跨过 N 帧，N 为正整数 | 正向计数增量 / S − N |
| Y 计数：按时间与频率 | 累计实际接收帧数；已知应收频率 F（帧/秒） | round(时间差 × F) − 实际接收增量 / S |

逐帧及固定抽样模式中，重复值不增加丢包或收到帧数，规则摘要显示重复采样数；非零增量不足正常跨帧数时提示配置或数据异常。固定抽样中正常跨过的 N 帧视作已收到，首点只计一帧，跳号超过 N 的部分计缺失；丢包率为累计缺失 /（累计缺失 + 累计推定收到帧数）。发送序号的缺口可能包括记录端未采到的帧，因此不能凭此区分通信丢包和记录缺失。

按时间模式的首点仅作为计数基线，收到帧数按后续实际计数增量累计；超过允许误差的正差额才计丢包，否则计零，误差不从已确认缺失数中扣减。实际增量超过预期量加容差及半帧舍入误差时提示异常。重复计数在此模式表示期间没有收到新帧，仍会按应收频率计算缺失。允许误差单位为帧，用于吸收采样抖动、计数更新相位；逐区间估计受误差配置影响。发送帧序号不能作为累计接收计数使用。采样规律和真实频率未知时，无法可靠计算丢包，不根据常见增量自动猜测。

回绕支持无回绕、8/16/32 位或自定义模数 M（2～4294967296），数值范围固定为 0～M−1；M 必须为每帧计数步长的整数倍。计数下降时补 M，例如 255→0 不丢包，254→1 缺失两帧。必须保证相邻采样实际正向计数增量小于半个范围；达到半范围的观测跳变、或按时间模式的预期量加容差达到半范围时拒绝计算。此约束不能识别所有复位、乱序或完整回绕：例如绕行一整圈后的相同值与重复值无法区分，应提高采样率或选择更大计数范围。

计数须为非负整数且不超过 double 精确整数范围，时间戳须有限且严格递增；步长不匹配、越界或可疑复位会使该规则输出失效并显示样本位置诊断。“自动识别”按所选累计/窗口统计方式建立 X 时间检测，Y 模式需手动选择计数信号。参数随 v15 会话保存，旧会话按 X 模式恢复。

### 输出指标（三选一）

新建丢包检测规则的“输出指标”下拉框有三个选项：

| 选项 | 结果 |
| --- | --- |
| 累计丢包数 | 从记录起点累计的缺失帧数，单位为帧 |
| 累计丢包率(%) | 从记录起点统计缺失 /（缺失 + 收到）×100% |
| 窗口丢包率(%) | 最近 W 秒内缺失 /（缺失 + 收到）×100%，默认选项 |

每条新规则只生成所选的一条结果，名称明确区分三个指标。“自动识别”同样默认窗口丢包率，并沿用下拉选择；选择其他指标后也只补充对应结果。窗口时长默认为 1 秒，可输入任意有限正数，仅选择窗口指标时显示。百分比不是累计丢包数对时间的微分（帧/秒）。

窗口模式在每个采样点 t 统计 (t−W,t] 内的丢失和接收增量，左端点不计入，右端点计入，起始不足一个窗口时使用已有数据。按原始采样点刷新，无数据期间不额外生成输出点。时间戳或计数跳变推断的缺失归入右端采样时刻，不均摊到间隔内，也不插值。因此大缺口后的第一个样本可能出现明显峰值，不能据此确定每一帧实际丢失的时刻。

例如 X 时间为 0、1、2、5、6、7 秒，周期 1 秒、窗口 2 秒：在 t=5 检出缺失 2 帧，窗口率为 66.67%；t=6 为 50%；t=7 时旧缺失移出窗口，窗口率归零。相同数据的累计丢包数在 t=7 为 2 帧，累计丢包率为 25%。Y 计数模式沿用各自的接收帧口径，重复值、回绕及基线处理不变。

同一配置中，自动识别仅复用相同采样组、指标及窗口时长的规则。新单输出规则切换指标保留输出 ID、手动样式及下游引用；自动名称随指标更新，手动名称保留。v17 会话保存单项输出；旧版双输出会话保留已有两条输出及其语义，避免破坏已有绘图和依赖。如需单项累计丢包数，请新建规则。
