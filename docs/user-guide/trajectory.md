# 三维运动轨迹

每个子图可以独立选择时间序列或航迹模式，两个模式可以混排。航迹选择两个坐标时为二维平面航迹，三个坐标时为三维空间航迹。

## 打开轨迹

1. 加载包含空间坐标的数据文件。
2. 在子图绘图区右键，选择“切换为航迹视图”。直接打开并激活该子图，默认经纬度模式，不弹出信号选择。
3. 从信号树按纬度、经度、高度顺序勾选或双击信号。新加入的信号自动填入第一个空轴；已有绑定不被替换，三轴满后继续选入的信号仅加入可用列表。按实际选入顺序绑定，不按信号名称猜测坐标类型。
4. 顶部下拉框默认使用刚选入的信号；可从已加入信号中调整纬度/经度/高度或空间 X/Y/Z 轴来源。绑定两个轴自动成为二维航迹，三个轴成为三维航迹。
5. 飞机经纬度数据可在“坐标”中选择经纬度投影类型，并设置纬度、经度、可选高度。下拉框仅列出本子图已经加入的信号。

顶部显示每个轴的来源，新增、移除、重命名或交换来源后立即刷新。下拉选项使用紧凑行高，长路径在中间省略并保留末尾信号名，悬停可查看完整路径。选择“不选（留空）”或右键轴下拉框取消该轴绑定，信号仍留在可用列表。选择已用于另一轴的信号时交换两轴来源。信号树取消勾选则移除该信号，并清空用到它的轴。每个子图的可用列表独立；首次进入航迹时已有时间图信号加入可用列表，同时按信号列表顺序填充空轴；再次进入保留已选模式与手动绑定。

信号树勾选显示当前活动子图的可用信号，不表示已经绑定到轴。点击航迹区可切换活动子图。“时间图”返回原时间序列视图，原信号绑定和视图范围保留；清空航迹来源也保留原时间图绑定。

所选坐标按同一原始样本的时间组成路径。信号样本数、逐点有效时间（包括时间偏移）须一致，时间须非递减；不进行插值或重采样。不符合条件时显示原因。任一已选坐标或时间缺失即断线，不连接缺口两侧的数据。留空的轴不参与样本校验、读数或导出。

## 同一子图多航迹

顶部航迹下拉框选择活动航迹，`+` 添加，`−` 删除；删除最后一条后留下空配置，仍可继续绑定。新增航迹沿用本子图的坐标类型（新子图默认经纬度），不自动复制坐标或姿态绑定。信号树新选入的信号填活动航迹的第一个空轴；轴满后只加入本子图共用候选列表。已在候选中的来源可通过坐标/姿态下拉框复用，绑定互不覆盖。树中取消某信号会将其从本子图候选移除，并清空所有航迹使用该来源的坐标或姿态绑定。

“显示”只控制活动航迹的显隐。“样式 / 姿态”以带字段标签的可滚动表单修改名称、颜色和线宽；长来源中间省略，悬停查看完整名称，下拉列表也保留完整悬停说明。重新打开从表单顶部显示。颜色可填 `#RRGGBB`、`#AARRGGBB` 或 Qt 色名，线宽 1–12。活动选择不改变其他航迹，也不自动移动相机。单子图最多 64 条。

地理航迹共用一个公共原点，不能各自首点归零。隐藏原点所属航迹仍保留该原点；删除或使它无效后，改由列表中下一条有效航迹提供原点，重新计算全部地理路径。原点纬度、经度和记录高度可在“样式 / 姿态”及底部悬停说明中查看。没有有效非零定位时使用该航迹的首个有效零定位。每条航迹内坐标时间基严格一致；不同航迹允许不同采样率。

所有可见有效航迹的范围用于公共中心与等比例投影；只有一套方向轴、旋转环和相机。两轴航迹全部属于相同平面时保持二维操作，否则使用公共三维视图。缺少轴、非法经纬度或时间基错误的航迹单独提示，不使其他有效航迹消失。适应视图排除隐藏与错误航迹。经纬度与空间 XYZ 不允许混用；空间输入必须已统一到同一导航坐标系。

## 测量三维姿态

在活动航迹的“样式 / 姿态”中选择欧拉角或四元数，再绑定候选列表中的测量信号。可先从信号树加入姿态来源；坐标轴满后它们不会覆盖坐标。开启单/双时间游标后，在对应航迹游标位置显示固定屏幕大小的简化飞机：随姿态旋转，大小不受路径缩放影响。飞机采用紧凑的机身/机翼/尾翼轮廓、对比填色和描边；姿态游标圆点缩小，文字移至模型右侧，避免挡住机身。

导航 NED 是北/东/下，机体 FRD 是前/右/下。零姿态将机头指向北、右翼指向东、机腹指向下。正滚转绕前轴使右翼向下；正俯仰绕右轴使机头向上；正航向绕下轴使机头由北转东。默认输入约定为度、列向量、主动机体→导航变换 `Rz(航向)·Ry(俯仰)·Rx(滚转)`。可改用弧度、`Rx·Ry·Rz` 或导航→机体方向（应用逆变换）。

四元数默认 `wxyz`、机体→导航，可改用 `xyzw` 和导航→机体。非零有限四元数归一化后使用，零模或不可表示的模长隐藏该样本；四元数 `q` 与 `−q` 表示相同方向。输入单位和变换约定不会从名称猜测，也不会用观察相机 `viewAngles` 代替测量姿态。

姿态各分量须使用相同时间基；姿态和位置之间可使用不同采样率。两者按共享游标分别查询最近原始有效样本，不插值、不跨缺失段、不向数据范围外延用末值。底部/悬停读数显示实际姿态时间，以及 `Δt = 姿态样本时间 − 位置样本时间`。游标处缺位置、缺姿态、来源被移除或姿态分量时间基不一致时隐藏相应模型并显示原因；不会沿用旧姿态。未开游标时显示启用提示。

## 视角与比例

- 三维航迹将 CAD 旋转环与左下角方向坐标轴合并。平时仅显示小坐标轴，鼠标靠近时展开旋转环；抓取后即使拖出角落仍保持展开，松开并离开后自动收起，不遮挡画面中央的航迹。
- 红环绕 X、绿环绕 Y、蓝环绕 Z：悬停对应环加粗，左键直接沿环拖动，可连续转过多圈。经纬度模式按 NED：X 向北、Y 向东、Z 向下。
- 角落“视角 X/Y/Z”显示当前实际画面的绝对姿态角，使用北东地（NED）方向：X 正北、Y 正东、Z 向下。零姿态为“正视 YZ”：X 指向屏幕内、Y 在屏幕向右、Z 垂直向下，三轴角度均为 0°。它根据当前相机方向计算，不是本次拖动量，松开、再次抓取或适应视图都不归零；切换预设视角、Ctrl+Z 或恢复会话后也反映该视角。移除零姿态的固定投影变换后，采用固定的 `Rz·Ry·Rx` 欧拉角表示，X/Y/Z 数值分别保持与对应方向轴一致的红/绿/蓝色，不随当前拖动轴整体变色：X/Z 为 ±180°，Y 为 ±90°，在 Y=±90° 时使用等价的 Z=0° 表示。完整转一圈后的姿态与转动前相同，因此读数不会显示累计圈数。
- 角落环内空白处左键拖动自由旋转；普通画布左键平移，Shift+左键在任何位置平移。中键、Alt+左键可直接自由旋转，使用画布快捷操作时无需展开角落环。彩色环在侧视下接近细线时，沿线拖动仍能绕对应轴旋转。
- 旋转支点始终是子图绘图区显示中心，与角落控件位置独立；旋转时中央仅短暂显示小十字，平移/缩放后仍围绕此中心旋转。正常沿环拖回按下位置可恢复本次拖动前的方向和位置，连续旋转不限制俯仰角。指针穿过环中心时暂停角度更新，离开中心后从新的指针位置续转，避免突然跳半圈；快速连续抓取也不会插入上一轮过期预览。
- 滚轮以鼠标所在位置缩放，缩放上限处停止；高倍放大仍可向四个方向平移。连续缩放后立即平移会保留最新缩放状态。旋转环的屏幕尺寸固定，小子图按空间缩小，不受数据范围、平移和缩放影响；会话继续保存旋转后的相机方向。
- 二维航迹左键拖动：平移；滚轮：缩放。空间坐标按所选 XY、XZ 或 YZ 显示，包含 Z 的平面以 Z 正方向向下；经纬度平面航迹东向右、北向上。
- “视角”菜单提供“俯视” XY、“正视” YZ、“侧视” XZ，以及“复位”到初始等轴测方向。二维航迹不显示空间旋转菜单。
- 鼠标在轨迹上时按空格，或右键选择“适应轨迹”，恢复适应比例与平移，保留旋转方向。
- 工具栏“自适应当前视图”作用于当前子图；“全部视图”分别适应二维和三维子图。旋转不会修改二维时间轴。
- Ctrl+Z 可以回退轨迹视角操作。

三轴使用同一个空间比例。外部坐标框已移除，左下角的小坐标轴跟随旋转，位置和大小不受平移/缩放影响；红色 X、绿色 Y、蓝色 Z。导航坐标使用 NED：X 北、Y 东、Z 下。空间 XYZ 原始值不做自动转换；叠加和姿态显示要求输入本身使用同一 NED 米制导航坐标系。机体系 FRD（前、右、下）单独定义，不能当作导航位置轴。

顶部为航迹管理与坐标绑定两排控件，底部仅一行读数；悬停底部可查看信号名称、全部起终点/游标读数和操作提示。游标启用时该行优先显示游标位置。航迹按当前投影范围适应画布宽、高，各边预留约 6% 边距，避免浅平路径缩在中央。

## 飞机经纬度 / 高度

输入顺序为**纬度（度）、经度（度）、高度（米）**，纬度范围 [-90,90]、经度 [-180,180]。不要将度和米混在空间 XYZ 模式里，水平运动会被高度比例压缩。

只看飞机水平位置时，把高度设为“不选（留空）”即可自动显示二维航迹，显示比例仍以米计；不会显示或导出虚构的零高度。需要观察升降时再选择高度恢复三维。

程序以航迹列表中首条有效地理航迹的首个同时有效且经纬度不同时为 0 的样本为公共原点，将 WGS84 椭球表面位置投影到该原点的局部北、东切平面，显示 **X 向北、Y 向东、Z 向下，单位均为米**。Z 使用原点高度减去记录高度，不加入地球曲率造成的下沉，适合观察飞行平面路径和升降变化；高度的原有基准不变。投影自动处理 ±180° 经线附近的位置，不会把相邻点分到画面两端。

仿真偶发的经纬度 `(0, 0)` 不参与整体自适应的中心和范围，避免正常航迹被压小；它仍保留在航迹连线、原始游标读数及导出中。仅纬度或仅经度为 0 仍是正常位置，空间 XYZ 的零点仍参与自适应。全部经纬度都是 `(0, 0)` 时使用这些样本作为有限范围回退。

起终点和游标的读数保留原始纬度、经度、记录高度。投影只影响显示，原始数据、游标时间及导出值不变。俯视为东/北平面，正视为东/高度，侧视为北/高度。投影适合局部飞行区域，跨洲或全球航迹不宜使用一个局部切平面衡量距离；不包含底图、地形或高度基准转换。

## 时间游标

起点为绿色，终点为红色。启用单/双游标后，时间序列图与航迹共享游标时间，航迹标记显示该时间附近的原始坐标样本，底部列出实际样本时间和坐标。左右方向键沿原始样本时间步进。

游标在缺失数据的时间区间或共享时间视窗之外时不显示轨迹位置。不显示插值坐标。轨迹本身显示全时段。

## 保存与导出

旧版经纬度视图的东/北/上显示基准改为 NED；读取旧会话时仍使用已保存相机数值，如需新的标准朝向，可选择“视角 → 正视 YZ”或复位。

会话 v6 保存每个子图的航迹列表、稳定身份、活动项、可用信号、全部坐标及姿态绑定、约定、样式、显隐和公共相机。读取 v1–v5 时转换为单航迹，姿态默认关闭。留空或已移除来源保存为 -1。选择绘制信号导出时，收集所有可见航迹实际坐标及启用姿态的来源并去重；保持原始数值，同表时间基仍须一致。

删除文件时，所有航迹中相应坐标与姿态来源置空；其他来源按文件身份重映射。清除航迹信号后可继续从信号树补选。

## 当前边界

此模式使用正交投影，路径按时间顺序绘制；模型和路径没有深度缓冲遮挡；不支持精细模型导入、纹理、光照、底图、地形或重放。首次准备空间简化索引在后台完成，旋转复用索引。静止时按约 0.25 像素的空间简化误差选择细节，随后可省略小于 0.35 像素的相邻点；拖动时对特别复杂的路径临时降低细节，松开后自动恢复精细显示。游标始终查询原始数据。极大或反复穿越画面的航迹仍需针对实际数据规模验证性能。

导航 NED 显示基准：X 北、Y 东、Z 下；机体 FRD 另为前、右、下。正视 YZ、俯视 XY、侧视 XZ，Z 正方向向下。

## 收起航迹配置

航迹默认只显示一条紧凑管理栏，保留航迹选择、显示开关、“配置”和“时间图”。点击“配置”展开添加/删除、样式与姿态、轴来源、坐标、视角和适应控件；“收起”将空间归还画布，底部读数不受影响。

每个子图独立记住展开状态，切换时间图再返回航迹仍保留；此偏好仅在当前运行期间生效，不写入会话。来源或姿态错误显示在底部，点击错误提示可展开配置。
