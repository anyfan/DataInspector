# 三维运动轨迹

每个子图可以独立选择时间序列或航迹模式，两个模式可以混排。航迹选择两个坐标时为二维平面航迹，三个坐标时为三维空间航迹。

## 打开轨迹

1. 加载包含空间坐标的数据文件。
2. 在子图绘图区右键，选择“切换为航迹视图”。直接打开并激活该子图，默认经纬度模式，不弹出信号选择。
3. 从信号树按纬度、经度、高度顺序勾选或双击信号。新加入的信号自动填入第一个空轴；已有绑定不被替换，三轴满后继续选入的信号仅加入可用列表。按实际选入顺序绑定，不按信号名称猜测坐标类型。
4. 顶部下拉框默认使用刚选入的信号；可从已加入信号中调整纬度/经度/高度或空间 X/Y/Z 轴来源。绑定两个轴自动成为二维航迹，三个轴成为三维航迹。
5. 飞机经纬度数据可在“坐标”中选择经纬度投影类型，并设置纬度、经度、可选高度。下拉框仅列出本子图已经加入的信号。

顶部显示每个轴的来源，新增、移除、重命名或交换来源后立即刷新。下拉选项使用紧凑行高，长路径在中间省略并保留末尾信号名，悬停可查看完整路径。选择“不选（留空）”或右键轴下拉框取消该轴绑定，信号仍留在可用列表。选择已用于另一轴的信号时交换两轴来源。信号树取消勾选则移除该信号，并清空用到它的轴。每个子图的可用列表独立；首次进入航迹时已有时间图信号加入可用列表，同时按信号列表顺序填充空轴；再次进入保留已选模式与手动绑定。

信号树勾选显示当前活动子图的可用信号，不表示已经绑定到轴。点击航迹区可切换活动子图。“时间图”返回原时间序列视图，原信号绑定和视图范围保留；清空航迹来源也保留原时间图绑定。

所选坐标按同一原始样本的时间组成路径。信号样本数、逐点有效时间（包括时间偏移）须一致，时间须非递减；不进行插值或重采样。不符合条件时显示原因。任一已选坐标或时间缺失即断线，不连接缺口两侧的数据。留空的轴不参与样本校验、读数或导出。

## 视角与比例

- 三维航迹将 CAD 旋转环与左下角方向坐标轴合并。平时仅显示小坐标轴，鼠标靠近时展开旋转环；抓取后即使拖出角落仍保持展开，松开并离开后自动收起，不遮挡画面中央的航迹。
- 红环绕 X、绿环绕 Y、蓝环绕 Z：悬停对应环加粗，左键直接沿环拖动，可连续转过多圈。经纬度模式按 NED：X 向北、Y 向东、Z 向下。
- 角落“视角 X/Y/Z”显示当前实际画面的绝对姿态角，使用北东地（NED）方向：X 正北、Y 正东、Z 向下。零姿态为“正视 YZ”：X 指向屏幕内、Y 在屏幕向右、Z 垂直向下，三轴角度均为 0°。它根据当前相机方向计算，不是本次拖动量，松开、再次抓取或适应视图都不归零；切换预设视角、Ctrl+Z 或恢复会话后也反映该视角。移除零姿态的固定投影变换后，采用固定的 `Rz·Ry·Rx` 欧拉角表示，X/Y/Z 数值分别保持与对应方向轴一致的红/绿/蓝色，不随当前拖动轴整体变色：X/Z 为 ±180°，Y 为 ±90°，在 Y=±90° 时使用等价的 Z=0° 表示。完整转一圈后的姿态与转动前相同，因此读数不会显示累计圈数。
- 角落环内空白处左键拖动自由旋转；普通画布左键平移，Shift+左键在任何位置平移。中键、Alt+左键可直接自由旋转，使用画布快捷操作时无需展开角落环。彩色环在侧视下接近细线时，沿线拖动仍能绕对应轴旋转。
- 旋转支点始终是子图绘图区显示中心，与角落控件位置独立；旋转时中央仅短暂显示小十字，平移/缩放后仍围绕此中心旋转。正常沿环拖回按下位置可恢复本次拖动前的方向和位置，连续旋转不限制俯仰角。指针穿过环中心时暂停角度更新，离开中心后从新的指针位置续转，避免突然跳半圈；快速连续抓取也不会插入上一轮过期预览。
- 滚轮以鼠标所在位置缩放，缩放上限处停止；高倍放大仍可向四个方向平移。连续缩放后立即平移会保留最新缩放状态。旋转环的屏幕尺寸固定，小子图按空间缩小，不受数据范围、平移和缩放影响；会话继续保存旋转后的相机方向。
- 二维航迹左键拖动：平移；滚轮：缩放。空间坐标按所选 XY、XZ 或 YZ 显示，包含 Z 的平面以 Z 正方向向下；经纬度平面航迹东向右、北向上。
- “视角”菜单提供“俯视” XY、“正视” YZ、“侧视” XZ，以及“复位”到初始等轴测方向。二维航迹不显示空间旋转菜单。
- 鼠标在轨迹上时按空格，或右键选择“适应轨迹”，恢复适应比例与平移，保留旋转方向。
- 工具栏“自适应当前视图”作用于当前子图；“全部视图”分别适应二维和三维子图。旋转不会修改二维时间轴。
- Ctrl+Z 可以回退轨迹视角操作。

三轴使用同一个空间比例。外部坐标框已移除，左下角的小坐标轴跟随旋转，位置和大小不受平移/缩放影响；红色 X、绿色 Y、蓝色 Z。空间 XYZ 使用前/右/下的显示基准，原始三轴值不做自动转换。机体系前右下（FRD）与地理 NED 并非同一坐标系；只有输入已是 NED 时，X/Y 才表示北/东。

顶部仅一排控件，底部仅一行读数；悬停底部可查看信号名称、全部起终点/游标读数和操作提示。游标启用时该行优先显示游标位置。航迹按当前投影范围适应画布宽、高，各边预留约 6% 边距，避免浅平路径缩在中央。

## 飞机经纬度 / 高度

输入顺序为**纬度（度）、经度（度）、高度（米）**，纬度范围 [-90,90]、经度 [-180,180]。不要将度和米混在空间 XYZ 模式里，水平运动会被高度比例压缩。

只看飞机水平位置时，把高度设为“不选（留空）”即可自动显示二维航迹，显示比例仍以米计；不会显示或导出虚构的零高度。需要观察升降时再选择高度恢复三维。

程序以首个同时有效且经纬度不同时为 0 的样本为原点，将 WGS84 椭球表面位置投影到该原点的局部北、东切平面，显示 **X 向北、Y 向东、Z 向下，单位均为米**。Z 使用原点高度减去记录高度，不加入地球曲率造成的下沉，适合观察飞行平面路径和升降变化；高度的原有基准不变。投影自动处理 ±180° 经线附近的位置，不会把相邻点分到画面两端。

仿真偶发的经纬度 `(0, 0)` 不参与整体自适应的中心和范围，避免正常航迹被压小；它仍保留在航迹连线、原始游标读数及导出中。仅纬度或仅经度为 0 仍是正常位置，空间 XYZ 的零点仍参与自适应。全部经纬度都是 `(0, 0)` 时使用这些样本作为有限范围回退。

起终点和游标的读数保留原始纬度、经度、记录高度。投影只影响显示，原始数据、游标时间及导出值不变。俯视为东/北平面，正视为东/高度，侧视为北/高度。投影适合局部飞行区域，跨洲或全球航迹不宜使用一个局部切平面衡量距离；不包含底图、地形或高度基准转换。

## 时间游标

起点为绿色，终点为红色。启用单/双游标后，时间序列图与航迹共享游标时间，航迹标记显示该时间附近的原始坐标样本，底部列出实际样本时间和坐标。左右方向键沿原始样本时间步进。

游标在缺失数据的时间区间或共享时间视窗之外时不显示轨迹位置。不显示插值坐标。轨迹本身显示全时段。

## 保存与导出

旧版经纬度视图的东/北/上显示基准改为 NED；读取旧会话时仍使用已保存相机数值，如需新的标准朝向，可选择“视角 → 正视 YZ”或复位。

会话 v5 保存可用信号列表、每个子图的模式、坐标类型、信号来源及自由旋转/缩放/平移，留空轴保存为 -1。可以读取 v1（默认时间序列）、v2（空间 XYZ）、v3（经纬度）及 v4（自由视角）会话；旧会话可在“坐标”里改为经纬度模式。选择“当前子图绘制信号”导出时，航迹贡献实际绑定到轴的源信号，按原格式导出时间和原始值。

删除文件时，其信号对应的轴置空；其他轴自动保留正确来源。清除航迹信号后可继续从信号树补选。

## 当前边界

此模式使用正交投影，路径按时间顺序绘制；没有深度缓冲遮挡、物体模型、姿态或重放。首次准备空间简化索引在后台完成，旋转复用索引。静止时按约 0.25 像素的空间简化误差选择细节，随后可省略小于 0.35 像素的相邻点；拖动时对特别复杂的路径临时降低细节，松开后自动恢复精细显示。游标始终查询原始数据。极大或反复穿越画面的航迹仍需针对实际数据规模验证性能。

空间坐标显示基准：X 前、Y 右、Z 下；NED 数据中分别为北、东、地。正视 YZ、俯视 XY、侧视 XZ，Z 正方向向下。
