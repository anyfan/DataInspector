# 渲染管线

曲线使用 GPU 三角带绘制，不依赖 `GL_LINE` 宽度。整条管线按"原始数据 → LOD → 屏幕几何 → QSG 节点"四级组织。

## PlotSeriesStore（不可变原始数据）

- `AppController` 共享唯一 Store；子图只保存有序系列 ID，不复制原始数组。
- 每个系列持有不可变 `QVector<double>` 时间与数值，以及数据代际号。
- 系列 ID 通过哈希索引定位，快照获取平均 O(请求数)。
- 画笔/时间偏移变化时只替换受影响系列的快照，旧快照仍可被游标安全读取。
- 调色板 14 色循环，恢复会话后继续导入按长度取模，不越界。

## PlotRangeIndex（分块极值索引）

加载线程每 512 个样本构建一个极值摘要，在摘要上建线段树：

- 摘要内容：块内 min/max、绝对值平均值、有效样本数、原始时间 min/max。
- 只统计时间和数值都有限的点；NaN/Inf 跳过但保留位置语义。
- 单调时间：二分定位样本区间，整块走树查询，边界扫描 < 1024 点。复杂度 O(log N + log(N/512))。
- 乱序时间：窗口外整块跳过、窗口内整块合并，部分相交块回退扫描。极端乱序窗口仍可能退化到 O(N)。
- 时间范围摘要独立于 Y 有效性：即使 Y 全是 NaN，有限时间仍参与 X 适应。
- 实测：100 万点单调序列全范围查询，原始样本扫描 574 次、索引节点读 15 个。

## PlotLodBuilder（min/max 保峰值降采样）

- 按当前视窗和屏幕宽度分桶，每桶保留 min/max 两个样本——缩小视图时尖峰和谷值不丢。
- NaN/无效样本分段，避免跨缺失数据产生幽灵连接。
- 单调序列保留视窗两侧连接点，保证平移时曲线连续。
- 浮点域判断桶边界，先归一化再转整数，避免远处连接点导致桶号溢出、极窄视窗桶宽下溢为 0。

## PlotLodScheduler（后台调度）

- 最多两个后台线程生成 LOD。
- 每子图合并最新请求，取消旧任务、丢弃过期结果。
- Y 范围和尺寸变化复用 LOD；游标移动复用曲线几何。
- 等待后台结果期间用旧 LOD 按新视窗投影，画面不空白。

## PlotGeometryBuilder（屏幕空间几何）

- 按画笔属性把 LOD 线段转成有限、裁剪后的屏幕空间三角带/三角形列表。
- 相邻样本对之间发常宽四边形；在非有限或 |像素| ≥ 1e8 处断开。
- 不使用整段折线三角形条带——否则缩放/平移时旧 LOD 会把条带内部填满，出现楔形。

## 曲线绘制层级（AmplitudeLayers）

`PlotItem::blendMode` 目前对外暴露两档：

- `AmplitudeLayers`（QML `blendOverlaps=true`，默认）：按当前可见区间内每条信号 `mean(abs(y))` 排序，幅值小的后画、叠在顶层，保留各自原色；点击选中的曲线额外置顶。
- `OpaqueBlend`（关闭上述选项）：按原始绑定顺序绘制，后画的覆盖先画的。

`plotblendmaterial.*` 复用 Qt 内置 `flatcolor` qsb 材质，仅通过 `updateGraphicsPipelineState` 设置混合方程。历史上曾提供 `Darken`/`Lighten`（`min`/`max`）两档做重叠区域的暗化/亮化混色，实际体验不好，已从 QML 菜单项移除；枚举值仍保留在头文件中以备复用，UI 不再切换。

## PlotItem（Scene Graph 项）

- 维护视图状态、交互、游标、QSG 节点。
- 曲线节点和材质复用，平移/缩放/游标更新不重建整棵节点树。
- 游标查询始终访问原始样本，不插值、不用 LOD。
- 归一化 Y 在 GUI 线程的 LOD 副本上就地缩放 y，共享 LOD 缓存仍是原始值；`fitY()` 在归一化模式下固定 `[-0.05, 1.05]`。

## 刻度

`render/plotaxisutils.*` 独立处理：

- 浮点起点 + 最多 12 次局部步进生成刻度，不把绝对刻度索引转整数（避免 Unix 时间戳溢出）。
- 标签重名时逐步提高有效数字到 17 位；零刻度精确显示 `0`。
- 自动适应使用有限可表示的边距；不可表示的跨度保留原视窗，不写入会话。
